## Basic example

The view switcher below uses the real Toggle Group. The pressed item receives the glass selected state and updates the text underneath.

Options are passed through the `items` array; each item's `value` maps to the group value.

Supports `xs` / `sm` / `md` / `lg` / `xl`, defaulting to `md`.

## Selection mode

`ToggleGroup` also forwards Base UI's `ToggleGroup` props such as `loopFocus`, `render`, and `ref`.

`style` is intentionally not supported: the glass theme owns the surface and the Base UI element. Use `className` for layout.

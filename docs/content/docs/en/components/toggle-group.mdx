## Props

### ToggleGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `readonly string[]` | — | Controlled pressed values. |
| `defaultValue` | `readonly string[]` | — | Initial pressed values. |
| `onValueChange` | `(value: string[], details) => void` | — | Called when the pressed values change. |
| `multiple` | `boolean` | `false` | Allows multiple pressed items. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout and keyboard orientation. |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | Controls item height, padding, text, and icons. |
| `disabled` | `boolean` | `false` | Disables every item. |
| `items` | `readonly ToggleGroupItemProps[]` | — | Options rendered by the group. |
| `className` | `any` | — | Tailwind classes merged into the group root. |

`ToggleGroup` also forwards Base UI's `ToggleGroup` props such as `loopFocus`, `render`, and `ref`.

`style` is intentionally not supported: the glass theme owns the surface and the Base UI element. Use `className` for layout.

### Item

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | Required value used by the group. |
| `label` | `ReactNode` | — | Visible content inside the item. |
| `icon` | `ReactNode` | — | Icon rendered before the label. |
| `aria-label` | `string` | — | Accessible name for icon-only items. |
| `aria-labelledby` | `string` | — | Names an icon-only item from another element. |
| `disabled` | `boolean` | `false` | Disables the item. |
| `className` | `string` | — | Tailwind classes merged into the item root. |

Items are plain objects; the group renders the Base UI toggle internally.

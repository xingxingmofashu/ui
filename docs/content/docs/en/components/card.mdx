`Card` is a native layout primitive rather than a Base UI component: it has no
interactive state and forwards its props directly to the root `div`. It is
server-safe and does not support Base UI's `render` prop.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | Card heading. |
| `description` | `ReactNode` | — | Supporting text below the heading. |
| `footer` | `ReactNode` | — | Footer action area. |
| `children` | `ReactNode` | — | Card body content. |
| `className` | `string` | — | Merged into `root`. |
| `ui` | `Partial<Record<CardThemeSlot, string>>` | — | Overrides internal slot styles. |

All other props are forwarded to the root `div`, such as `id`, `role`, and `onClick`.

### UI Slots

| Slot | Description |
| --- | --- |
| `root` | Outermost container. |
| `header` | Title and description region. |
| `title` | Heading element. |
| `description` | Description element. |
| `body` | Main content region. |
| `footer` | Footer region. |

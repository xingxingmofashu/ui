## Basic example

Each entry in `items` renders a real heading and button. The default plus indicator rotates into a close icon, and the panel animates its height.

## Multiple panels

The default mode keeps a single panel open. Add `multiple` to let several panels stay expanded at once:

## Sizes

Supports `xs` / `sm` / `md` / `lg` / `xl`, defaulting to `md`. Trigger height, padding, typography, and the indicator scale together.

<Example name="accordion/sizes" />

`value` and `onValueChange` make the open panels fully controlled. The example below can open or collapse every panel from one button:

Set `disabled` on the root to disable every trigger, or on a single item to disable only that panel.

`Accordion` also forwards Base UI `Accordion.Root` props such as `render` and `ref`.

`style` is intentionally not supported: the glass theme owns the surface and the Base UI element. Use `className` for layout. Accordion styling is internal and is not customizable per instance; tune it through the shared `--ui-glass-*` tokens instead.

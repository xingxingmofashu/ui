---
title: "Popover"
description: "A non-modal React popover with a Liquid Glass panel anchored to a trigger."
---

`Popover` is an integrated wrapper around Base UI's `Popover`. It renders the trigger, portal, positioner, glass popup, directional arrow, title, description, optional body, and optional action area internally. The arrow follows the resolved side of the popup automatically; set `arrow={false}` to hide it.

Unlike `Dialog` and `Drawer`, `Popover` is non-modal by default: focus is not trapped, the page stays scrollable, and pressing outside or Escape closes it. Use it for compact settings, contextual actions, and filters.

## Basic example

Pass one element as `trigger`. It must forward props and refs to its root element, as `Button` does. Base UI adds `aria-haspopup="dialog"` and `aria-expanded` to the trigger automatically, and clicking it toggles the popover. This example is uncontrolled.

## Controlled usage

`open` and `onOpenChange` control visibility. Footer buttons do not close the popover automatically; update `open` yourself as the example does.

<Example name="popover/controlled" />

## Placement

`side`, `align`, `sideOffset`, and `alignOffset` are forwarded to Base UI's positioner. Base UI flips or shifts the popup when it would overflow the viewport.

`Popover` also forwards Base UI `Popover.Root` props such as `actionsRef`, `handle`, `triggerId`, and `defaultTriggerId`.

`style` is intentionally not supported: the glass theme owns the positioner, popup, and content. Use `className` for popup layout. Popover styling is internal and is not customizable per instance; tune it through the shared `--ui-glass-*` tokens instead.

Base UI supplies the `dialog` role, `aria-labelledby` from the title, `aria-describedby` from the description, focus return, outside-press dismissal, and Escape dismissal.

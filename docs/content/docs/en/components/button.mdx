## Sizes

Supports `xs` / `sm` / `md` / `lg` / `xl`, defaulting to `md`. Text and icons scale with the size, so you do not need to pass `size` to icons separately.

<Example name="button/sizes" />

## Icons

The leading icon sits before the label. The trailing icon sits after the label. Both use the same plain icon container.

<Example name="button/icons" />

## States

The disabled state uses the native `disabled` attribute, stopping both keyboard and pointer interaction. `focusableWhenDisabled` keeps the button in the Tab order while disabled; Base UI exposes it with `aria-disabled` and blocks activation.

All other props are forwarded to the Base UI `Button`, including `disabled`, `focusableWhenDisabled`, `nativeButton`, `onClick`, `type`, `render`, and `ref`.

`style` is intentionally not supported: the glass theme owns the surface and the Base UI element. Use `className` for layout. The glass material is internal and is not customizable per button; tune it through the shared `--ui-glass-*` tokens instead.

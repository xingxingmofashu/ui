## Basic example

The switch below is the real component and can be clicked directly.

<Example name="switch/basic" />

The Base UI `Switch.Root` is the outermost element. The visual track is the
inner `base` slot, and the whole row, including the label and description, is
clickable. `label` becomes the accessible name through `aria-labelledby`; when
the control has a label or explicit name, `description` is linked through
`aria-describedby`. An explicit `aria-label` or `aria-labelledby` takes
precedence for the name, and an explicit `aria-describedby` is merged with the
description. A description-only control uses the description as its name and
does not add `aria-describedby`.

## Sizes

All other props are forwarded to Base UI's `Switch.Root`, including `required`, `name`, `form`, `value`, `uncheckedValue`, `inputRef`, `nativeButton`, `render`, and `ref`.

`style`, `baseStyle`, and `baseClassName` are intentionally not supported: the glass theme owns the root and every Base UI part. Use `className` for root layout.

`Slider` is a styled wrapper around Base UI's `Slider.Root`. It renders the control, track, indicator, and glass thumb internally. Props are forwarded to `Slider.Root`; `style` and `children` are intentionally not supported.

## Accessible name

Slider does not render a visible label. Point `aria-labelledby` at a visible label, or pass `aria-label`; both are forwarded from the root to every thumb, and `aria-describedby` is forwarded as well. For range sliders, use `getAriaLabel` to name each thumb.

`aria-invalid` and `aria-errormessage` are applied to the underlying `input[type="range"]`, so validation state supplied by a form library reaches the focusable control. A plain `aria-label` is shared by every thumb in a range slider; pass `getAriaLabel` when each thumb needs a distinct name.

## Range values

Passing an array renders one thumb per value. `format` follows `Intl.NumberFormatOptions` and is applied to the thumb's accessible value text.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number \| readonly number[]` | — | Controlled value; an array renders one thumb per value. |
| `defaultValue` | `number \| readonly number[]` | — | Uncontrolled initial value. |
| `onValueChange` | `(value, details) => void` | — | Called when the value changes. |
| `onValueCommitted` | `(value, details) => void` | — | Called when a value change is committed. |
| `name` | `string` | — | Field name used when submitting a form. |
| `form` | `string` | — | Identifies the form that owns the slider inputs. |
| `min` | `number` | `0` | Minimum value. |
| `max` | `number` | `100` | Maximum value. |
| `step` | `number` | `1` | Step for dragging and arrow keys. |
| `largeStep` | `number` | `10` | Step for Page Up / Page Down and Shift + arrow keys. |
| `minStepsBetweenValues` | `number` | `0` | Minimum steps between range thumb values. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout and keyboard orientation. |
| `format` | `Intl.NumberFormatOptions` | — | Value format used by Base UI's accessible value text. |
| `locale` | `Intl.LocalesArgument` | — | Locale used for number formatting. |
| `getAriaLabel` | `(index: number) => string` | — | Accessible name for the thumb at the given index. Use it for range sliders. |
| `getAriaValueText` | `(formattedValue, value, index) => string` | — | Custom accessible value text for each thumb. |
| `aria-label` | `string` | — | Accessible name shared by every thumb. |
| `aria-labelledby` | `string` | — | ID reference for an external accessible name. |
| `aria-describedby` | `string` | — | ID reference for supporting text announced with each thumb. |
| `aria-invalid` | `boolean \| "grammar" \| "spelling" \| "true" \| "false"` | — | Marks the underlying range input as invalid. |
| `aria-errormessage` | `string` | — | ID of the error message associated with the underlying range input. |
| `disabled` | `boolean` | `false` | Disables the slider. |
| `thumbAlignment` | `"center" \| "edge" \| "edge-client-only"` | `"center"` | How thumbs align with the control edges. |
| `thumbCollisionBehavior` | `"push" \| "swap" \| "none"` | `"push"` | How range thumbs behave when they collide. |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | — | Replaces the root element. |
| `ref` | `Ref<HTMLDivElement>` | — | Ref forwarded to the root element. |
| `className` | `string` | — | Tailwind classes merged into the outermost root. |

| Attribute | Description |
| --- | --- |
| `data-dragging` | Present while a thumb is being dragged. |
| `data-orientation` | Indicates the orientation (`horizontal` or `vertical`). |
| `data-disabled` | Present when the slider is disabled. |
| `data-index` | Indicates the thumb index on range sliders. |
| `data-valid` | Present when the slider is valid (inside `Field.Root`). |
| `data-invalid` | Present when the slider is invalid (inside `Field.Root`). |
| `data-touched` | Present after the slider is touched (inside `Field.Root`). |
| `data-dirty` | Present after the slider value changes (inside `Field.Root`). |
| `data-focused` | Present when the slider is focused (inside `Field.Root`). |

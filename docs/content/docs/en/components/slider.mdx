---
title: "Slider"
description: "A liquid glass slider built on Base UI Slider.Root, supporting single values, ranges, and vertical orientation."
---

`Slider` is a styled wrapper around Base UI's `Slider.Root`. It renders the control, track, indicator, and glass thumb internally. Props are forwarded to `Slider.Root`; `style` and `children` are intentionally not supported.

## Accessible name

Slider does not render a visible label. Point `aria-labelledby` at a visible label; Base UI forwards it from the root to every thumb. `aria-label` and `aria-describedby` stay on the root.

## Range values

Passing an array renders one thumb per value. `format` follows `Intl.NumberFormatOptions` and is applied to the thumb's accessible value text.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number \| readonly number[]` | — | Controlled value; an array renders one thumb per value. |
| `defaultValue` | `number \| readonly number[]` | — | Uncontrolled initial value. |
| `onValueChange` | `(value, details) => void` | — | Called when the value changes. |
| `onValueCommitted` | `(value, details) => void` | — | Called when a value change is committed. |
| `name` | `string` | — | Field name used when submitting a form. |
| `form` | `string` | — | Identifies the form that owns the slider inputs. |
| `min` | `number` | `0` | Minimum value. |
| `max` | `number` | `100` | Maximum value. |
| `step` | `number` | `1` | Step for arrow keys and dragging. |
| `largeStep` | `number` | `10` | Step for Page Up / Page Down and Shift + arrow keys. |
| `minStepsBetweenValues` | `number` | `0` | Minimum steps between range thumb values. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout and keyboard orientation. |
| `format` | `Intl.NumberFormatOptions` | — | Value format used by Base UI's accessible value text. |
| `locale` | `Intl.LocalesArgument` | — | Locale used for number formatting. |
| `disabled` | `boolean` | `false` | Disables the slider. |
| `thumbAlignment` | `"center" \| "edge" \| "edge-client-only"` | `"center"` | How thumbs align with the control edges. |
| `thumbCollisionBehavior` | `"push" \| "swap" \| "none"` | `"push"` | How range thumbs behave when they collide. |
| `className` | `any` | — | Tailwind classes merged into the outermost `root`. |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | — | Replaces the root element. |

`ref` is forwarded to the root. Other native props are forwarded as well.

`style` is intentionally not supported: the glass theme owns the surface and the Base UI element. Use `className` for layout. Slider styling is internal and is not customizable per instance; tune it through the shared `--ui-glass-*` tokens instead.

---

`AlertDialog` is an integrated wrapper around Base UI's `AlertDialog`. It renders the portal, backdrop, centered popup, title, description, optional body, and fixed cancel and confirm actions internally.

## Basic example

The component is fully controlled: `open` controls visibility and the page renders its own trigger button. It is modal and pressing the backdrop does not dismiss it; the user has to choose an action.

<Example name="alert-dialog/basic" />

## Controlled usage

`open` and `onOpenChange` control the dialog. Render your own button and set `open` to `true` to show it; `onConfirm` and `onCancel` handle action side effects.

`AlertDialog` also forwards Base UI `AlertDialog.Root` props such as `actionsRef`, `handle`, `triggerId`, and `defaultTriggerId`.

`style` is intentionally not supported: the glass theme owns the backdrop, popup, and content. Use `className` for popup layout. Dialog styling is internal and is not customizable per instance; tune it through the shared `--ui-glass-*` tokens instead.

The action area is fixed to a cancel and a confirm button, both using the package `Button`. In controlled mode, update `open` from `onOpenChange`.

Base UI supplies the `alertdialog` role, `aria-labelledby` from the title, `aria-describedby` from the description, focus trapping, scroll locking, and focus return.

`AlertDialog` is an integrated wrapper around Base UI's `AlertDialog`. It renders the trigger, portal, backdrop, centered popup, title, description, optional body, and the action buttons internally.

## Controlled usage

`open` and `onOpenChange` control the dialog. Omit `trigger` to open it programmatically. `onConfirm` and `onCancel` run before the dialog closes.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `trigger` | `ReactElement` | — | Element that opens the dialog. Omit it for a fully controlled dialog. |
| `title` | `ReactNode` | — | Dialog heading. |
| `description` | `ReactNode` | — | Supporting copy under the title. |
| `children` | `ReactNode` | — | Extra content between the description and the actions. |
| `cancelLabel` | `ReactNode` | `"Cancel"` | Cancel action label. Set to `null` to hide the action. |
| `confirmLabel` | `ReactNode` | `"Confirm"` | Confirm action label. Set to `null` to hide the action. |
| `onConfirm` | `MouseEventHandler<HTMLButtonElement>` | — | Called when the confirm action is pressed. |
| `onCancel` | `MouseEventHandler<HTMLButtonElement>` | — | Called when the cancel action is pressed. |
| `open` | `boolean` | — | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Initial open state when uncontrolled. |
| `onOpenChange` | `(open: boolean, details) => void` | — | Called when the dialog opens or closes. |
| `onOpenChangeComplete` | `(open: boolean) => void` | — | Called after the open or close animation finishes. |
| `className` | `any` | — | Tailwind classes merged into the popup. |

`AlertDialog` also forwards Base UI `AlertDialog.Root` props such as `actionsRef`, `handle`, `triggerId`, and `defaultTriggerId`.

`style` is intentionally not supported: the glass theme owns the backdrop, popup, and content. Use `className` for popup layout. Dialog styling is internal and is not customizable per instance; tune it through the shared `--ui-glass-*` tokens instead.

The cancel and confirm actions use the package `Button`. Confirming closes the dialog after `onConfirm` runs. In controlled mode, update `open` from `onOpenChange`.

Base UI supplies the `alertdialog` role, `aria-labelledby` from the title, `aria-describedby` from the description, focus trapping, scroll locking, and focus return.

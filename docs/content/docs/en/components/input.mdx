title: "Input"

`Input` renders a glass control with a native `<input>`, an optional label and description, and optional leading and trailing icons.

The visible label is a real `<label>` associated with the input. When `description` is set, it receives an id and the input points at it with `aria-describedby`; any `aria-describedby` you pass is merged with that id.

## Basic example

Use `value` with `onValueChange` for a controlled field, or `defaultValue` for an uncontrolled one. All native input attributes such as `type`, `name`, `placeholder`, `required`, and `readOnly` are forwarded.

## Sizes

Five sizes are available: `xs`, `sm`, `md`, `lg`, and `xl`. Height, padding, radius, text, and icon sizes scale together.

## Icons

`leadingIcon` renders before the input and `trailingIcon` after it. Both slots are decorative and receive `aria-hidden="true"`; use the label or `aria-label` for the accessible name.

## States

`disabled` is forwarded to the native input and fades the whole field. `readOnly` keeps the value focusable and selectable while preventing edits.

## Accessibility

`Input` renders a native `<input>` with a real `<label>` when `label` is set. `description` is connected with `aria-describedby`, and any `aria-describedby` you pass is merged.

Use `aria-label` or `aria-labelledby` only when no visible label is rendered; placeholder text is not a label. Icon slots are decorative. Native attributes such as `required`, `name`, and `type` keep native form behavior. See the [accessibility guide](/docs/en/guides/accessibility) for labeling patterns.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | Visible label associated with the input. |
| `description` | `ReactNode` | — | Supporting text under the control, linked through `aria-describedby`. |
| `leadingIcon` | `ReactNode` | — | Decorative icon before the input. |
| `trailingIcon` | `ReactNode` | — | Decorative icon after the input. |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | Controls height, padding, radius, text, and icon size. |
| `value` | `string \| number \| readonly string[]` | — | Controlled value. |
| `defaultValue` | `string \| number \| readonly string[]` | — | Initial value when uncontrolled. |
| `onValueChange` | `(value: string, details) => void` | — | Called when the value changes. |
| `type` | `HTMLInputTypeAttribute` | `"text"` | Native input type. |
| `placeholder` | `string` | — | Placeholder text. |
| `name` | `string` | — | Form field name. |
| `id` | `string` | generated | ID of the input. A generated ID is used when omitted. |
| `disabled` | `boolean` | `false` | Disables the input and fades the whole field. |
| `readOnly` | `boolean` | `false` | Prevents edits while keeping the value focusable and selectable. |
| `required` | `boolean` | `false` | Requires a value for form submission. |
| `aria-label` | `string` | — | Accessible name when no visible label is rendered. |
| `aria-labelledby` | `string` | — | ID reference for an external accessible name. |
| `aria-describedby` | `string` | — | ID reference for extra supporting text. A visible `description` is merged with this value. |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | — | Replaces the input element. |
| `ref` | `Ref<HTMLElement>` | — | Ref forwarded to the input element. |
| `className` | `string` | — | Tailwind classes merged into the outer root. |
| `ui` | `{ root?: ClassValue; label?: ClassValue; control?: ClassValue; glass?: ClassValue; overlay?: ClassValue; leadingIcon?: ClassValue; input?: ClassValue; trailingIcon?: ClassValue; description?: ClassValue }` | — | Tailwind classes for internal slots, keyed by `data-slot`. |

| Attribute | Description |
| --- | --- |
| `data-disabled` | Present when the input is disabled. |
| `data-valid` | Present when the input is valid. |
| `data-invalid` | Present when the input is invalid. |
| `data-touched` | Present after the input is touched. |
| `data-dirty` | Present after the input value changes. |
| `data-filled` | Present when the input has a value. |
| `data-focused` | Present when the input is focused. |
| `data-slot` | Marks internal parts (`root`, `label`, `control`, `glass`, `overlay`, `leading-icon`, `input`, `trailing-icon`, `description`) for styling. |

---
title: "Installation"
description: "Install Liquid Glass UI and add the glass styles to your Tailwind CSS entry."
---

Requires Node.js 22+, React 19, and Tailwind CSS 4.

```bash
pnpm add @xingxingmofashu/ui
```

The package is published under the `latest` dist-tag.

Add the package styles to your Tailwind CSS entry:

```css
@import "tailwindcss";
@import "@xingxingmofashu/ui";
```

The package root resolves to `dist/index.css` through its `style` export. The
stylesheet includes its own Tailwind source scan, so no extra `@source`
directive is needed.

Then import components from the package root:

```tsx
import { Button } from "@xingxingmofashu/ui";

export function Example() {
  return <Button label="Continue" />;
}
```

## Before you start

Every guide assumes:

- React 19 and React DOM 19.
- Tailwind CSS 4 with `@import "@xingxingmofashu/ui";` in the global stylesheet.
- A current evergreen browser with `backdrop-filter`, `color-mix`, container
  units, and `:has`.

If you have not installed the package yet, begin with
[Installation](/docs/en/get-started/installation). Component-level examples and
prop tables live under [Components](/docs/en/components).

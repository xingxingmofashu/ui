## 开始之前

每篇指南都假设：

- React 19 与 React DOM 19。
- Tailwind CSS 4，并在全局样式表中写入
  `@import "@xingxingmofashu/ui";`。
- 使用支持 `backdrop-filter`、`color-mix`、容器单位与 `:has` 的现代常青浏览器。

如果还没有安装组件包，请先阅读[安装](/docs/zh/get-started/installation)。
组件级示例与属性表位于[组件](/docs/zh/components)。

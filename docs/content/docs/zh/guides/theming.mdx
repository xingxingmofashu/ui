组件包提供一个样式表，其中包含设计 token、共享玻璃材质与 Tailwind 源码扫描配置。
在全局 CSS 中导入一次，其余布局围绕它来组织。

```css [app.css]
@import "tailwindcss";
@import "@xingxingmofashu/ui";
```

## 明暗主题

Token 通过 `.light` / `.dark` 类或 `data-theme="light"` /
`data-theme="dark"` 属性切换。即使没有主题选择器，默认也是浅色。

```html [index.html]
<html class="dark">
```

```html [index.html]
<html data-theme="dark">
```

两种机制可以互换。在深色文档中，嵌套的 `.light` 或
`[data-theme="light"]` 子树可以切回浅色 token，适合局部预览与独立面板。

```html
<html class="dark">
  <body>
    <main class="dark">...</main>
    <aside data-theme="light">...</aside>
  </body>
</html>
```

尽量在首次绘制前设置主题。在渲染期间读取 `localStorage` 会导致 hydration
不匹配；应在内联脚本中设置类名，或使用 `next-themes` 之类的主题库，并在
`<html>` 上添加 `suppressHydrationWarning`。

## 玻璃预设

可选的预设样式表内置三组共享材质。在主样式表之后导入：

```css [app.css]
@import "@xingxingmofashu/ui";
@import "@xingxingmofashu/ui/plugins/glass-preset/preset.css";
```

不导入 `preset.css` 时，主样式表仍然使用默认的 `regular` 材质；只有导入后
`data-glass` 属性才会生效。在根元素或任意容器上设置 `data-glass`：

```html [index.html]
<html data-glass="thin">
```

```html
<section data-glass="thick">
  <Card>...</Card>
</section>
```

| 预设 | 浅色遮罩 | 深色遮罩 | 模糊 | 饱和度 | 适用场景 |
| --- | --- | --- | --- | --- | --- |
| `thin` | `20%` | `62%` | `4px` | `150%` | 安静背景上的装饰性表面 |
| `regular` | `35%` | `68%` | `16px` | `140%` | 大多数页面的默认材质 |
| `thick` | `45%` | `72%` | `16px` | `140%` | 文字密集、照片背景复杂 |

没有 `data-glass` 属性时同样使用 `regular`。预设只修改共享的
`--ui-glass-*` 变量；组件内部、布局与文字样式保持不变。预设会继承到后代，
`light-dark()` 数值跟随当前的 `color-scheme`，因此深色页面中的预设会自动
使用深色值。嵌套的 `.light` 或 `.dark` 子树会回到默认的 `regular` 材质；
如果预设需要跨过该主题边界，请在子树上也加上 `data-glass`。

运行时切换只需要修改属性，不需要改组件代码：

```tsx
document.documentElement.dataset.glass = "thick";
```

### 预设插件

可选的 React 入口负责属性同步、受控状态与持久化。它不会自动导入 CSS，请
保留上面的预设样式表导入。

```tsx [app/layout.tsx]
import type { ReactNode } from "react";

import {
  GlassPresetProvider,
  GlassPresetScript,
} from "@xingxingmofashu/ui/plugins/glass-preset";

export default function RootLayout({
  children,
}: {
  children: ReactNode;
}) {
  return (
    <html lang="zh-CN" suppressHydrationWarning>
      <head>
        <GlassPresetScript storageKey="app-glass" defaultPreset="regular" />
      </head>
      <body>
        <GlassPresetProvider
          defaultPreset="regular"
          storageKey="app-glass"
        >
          {children}
        </GlassPresetProvider>
      </body>
    </html>
  );
}
```

`GlassPresetScript` 在 React 水合之前执行并恢复已保存的预设，避免先显示默认
材质再切换。Provider 读取同一个 key，把 `data-glass` 写到 `<html>`，并通过
`useGlassPreset` 暴露当前值：

```tsx
const { preset, setPreset } = useGlassPreset();
```

需要受控状态时传入 `preset` 与 `onPresetChange`。`storageKey` 是可选的；
如果应用自己管理持久化，可以不传。

使用 `GlassPresetScope` 可以只改变某个容器的预设，不影响全局值。它渲染一个
带 `data-glass` 的 `div`，并接受普通 `div` 属性：

```tsx
<GlassPresetScope preset="thick">
  <Card>...</Card>
</GlassPresetScope>
```

如果内联脚本无法放在文档 head 中，可以用 `getGlassPresetScript` 生成相同的
脚本，再交给框架的脚本注入 API。

完整插件 API、受控状态与水合行为见[玻璃预设](/docs/zh/plugins/glass-preset)。

## Token 分层

材质分为两层：

- **运行时 token** 随主题变化：`--ui-ink`、`--ui-ink-active`、`--ui-surface`、
  `--ui-glass-surface`、`--ui-glass-border`、`--ui-glass-highlight`、
  `--ui-glass-rim`、`--ui-glass-focus`、`--ui-shadow-glass` 和
  `--ui-drop-shadow-label`。
- **共享几何参数** 在明暗主题中保持一致：`--ui-glass-blur`、
  `--ui-glass-saturate`、`--ui-glass-inner-inset`、`--ui-glass-rim-inset`
  等共享的 `--ui-glass-*` 参数。checkbox 的 rim、slider 的 lens 等组件专属
  数值保留在该组件的主题配置中。

组件包在 `@layer theme` 中定义这些值。因此应用里未分层的 `:root` 无需
`!important` 就能覆盖：

```css [app.css]
@import "tailwindcss";
@import "@xingxingmofashu/ui";

:root {
  --ui-glass-surface: rgb(255 255 255 / 0.5);
  --ui-glass-border: rgb(15 23 42 / 0.16);
  --ui-glass-blur: 20px;
  --ui-glass-saturate: 160%;
}

.dark,
[data-theme="dark"] {
  --ui-glass-surface: rgb(20 20 20 / 0.75);
  --ui-glass-border: rgb(255 255 255 / 0.24);
}
```

默认的 `regular` 材质使用 35% 浅色遮罩或 68% 深色遮罩，搭配 16px 模糊与
140% 饱和度。遮罩强度需要在通透感和文字对比度之间取舍，请按应用中的图片来
调整：在最复杂、最暗的背景上测试，而不只是纯色页面。

## Tailwind 别名

样式表为常用 token 提供了 Tailwind 颜色别名：

| 工具类 | Token |
| --- | --- |
| `text-ui-ink`、`bg-ui-ink` | `--ui-ink` |
| `bg-ui-glass-surface` | `--ui-glass-surface` |
| `border-ui-glass-border` | `--ui-glass-border` |
| `outline-ui-glass-focus` | `--ui-glass-focus` |
| `bg-ui-surface` | `--ui-surface` |

为自己的布局使用这些别名，可以让自定义界面跟随组件主题。需要一次性数值时，
仍然可以使用任意值：

```tsx
<div className="rounded-3xl border border-ui-glass-border bg-ui-glass-surface p-6 text-ui-ink">
  与组件材质保持一致。
</div>
```

## 自定义玻璃表面

共享材质也以 CSS 类导出。需要组件库未提供的玻璃面板时，可以组合这些类：

```tsx
<div className="ui-glass ui-glass-inner ui-glass-highlight relative overflow-hidden rounded-3xl p-6">
  <span aria-hidden="true" className="ui-glass-rim" />
  <p className="relative z-10 text-sm text-ui-ink">自定义玻璃面板</p>
</div>
```

- `.ui-glass` 绘制半透明填充、双层边框、镜面阴影与背景模糊。
- `.ui-glass-inner` 通过 `::before` 添加柔和内轮廓。
- `.ui-glass-highlight` 通过 `::after` 添加对角高光。
- `.ui-glass-rim` 是装饰性子元素，请加上 `aria-hidden="true"`。
- `.ui-glass-chip` 是用于小型读数等紧凑表面的样式。

大多数组件已经组合了这些类。只有组件库没有提供对应表面时，才需要直接使用它们。

## 组件级样式

每个组件都接受 `className`。它会合并到组件的主要元素：大多数组件是根元素，
浮层组件是弹窗，`Toast` 则是每条通知。用它处理布局，而不是替换材质：

```tsx
<Button className="w-full" label="继续" />
```

每个组件还接受 `ui`，其键对应组件的 `data-slot` 名称。用它调整内部槽位的样式，
同时保持单结构 API：

```tsx
<Card
  title="部署"
  description="生产环境"
  ui={{
    glass: "bg-white/40",
    header: "pb-0",
    title: "tracking-tight",
  }}
>
  <p className="text-sm text-ui-ink/70">Build 128 已上线。</p>
</Card>
```

值为 `ClassValue`，因此支持字符串、数组与类名映射。合并顺序是主题配方、`ui`、
`className`；对于 Accordion、Toggle Group 这类集合组件，先应用根 `ui`，再应用
每个 item 的 `ui`，最后是 item 的 `className`。可查看 DOM 的 `data-slot` 属性
或组件 API 表中的槽位列表。

大多数组件有意不支持 `style`，因为玻璃主题拥有表面。用 `ui` 与 `className`
处理间距、宽度与定位，用共享 token 调整颜色、模糊与阴影。

需要完全控制时，可以导入编译后的主题配方：

```tsx
import buttonTheme from "@xingxingmofashu/ui/theme/button";

const styles = buttonTheme({ size: "lg" });

export function CustomButton() {
  return <button className={styles.root()}>自定义操作</button>;
}
```

配方返回各插槽的类名，自定义组件可以复用相同的几何与材质，而不必复制
Tailwind 类。

## 动效与浏览器支持

过渡与按压效果都包含 `motion-reduce` 变体。设置
`prefers-reduced-motion: reduce` 的用户仍会看到布局与状态变化，但装饰性动效会
被移除或缩短。

视觉材质依赖现代 CSS：`backdrop-filter`、`color-mix`、容器单位、独立的
`translate` / `scale` 属性，以及 `:has`。对于不支持 `backdrop-filter` 的
浏览器，请提供合理的背景回退，或将支持范围限制在现代常青浏览器。

## 检查清单

- 只导入一次组件样式表，并放在自定义覆盖之前。
- 在首次绘制前设置 `.dark` 或 `data-theme="dark"`。
- 共享材质用 `data-glass="thin | regular | thick"` 切换。
- 自定义材质在未分层的 `:root` 与 `.dark` 块中覆盖 token。
- 在应用中最复杂的背景上测试玻璃对比度。
- 内部槽位优先用 `ui`，布局优先用 `className`，材质变化优先用 token。

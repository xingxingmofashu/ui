这里是 Liquid Glass UI（`@xingxingmofashu/ui`）的文档站。组件基于 React 19 与 Tailwind CSS 4；Accordion、Alert Dialog、Button、Slider、Switch 与 Toggle Group 使用 Base UI，Card 使用原生结构。表面、边框高光与内阴影全部由 CSS 绘制，没有贴图，也没有额外的运行时。

整个文档站使用黑白主题：导航、代码高亮、提示框与组件示例都保持中性色。下面的折叠面板、卡片、按钮、滑块与开关直接来自 UI 包本身。

## 设计原则

- **真实组件**：文档通过 MDX 直接渲染 `@xingxingmofashu/ui`，预览与组件源码完全一致。
- **黑白优先**：文档使用 Fumadocs 的黑色主题，并覆盖提示框与代码高亮为中性色。
- **可覆盖**：`className` 控制根元素，共享的 `--ui-*` token 控制主题。

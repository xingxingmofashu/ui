        <CodeBlockTabsTrigger value="yarn">yarn</CodeBlockTabsTrigger>
        <CodeBlockTabsTrigger value="npm">npm</CodeBlockTabsTrigger>
        <CodeBlockTabsTrigger value="bun">bun</CodeBlockTabsTrigger>
      </CodeBlockTabsList>
      <CodeBlockTab value="pnpm">

        ```bash
        pnpm add @xingxingmofashu/ui
        ```

      <CodeBlockTab value="yarn">
        ```bash
        yarn add @xingxingmofashu/ui
        ```
      </CodeBlockTab>
      <CodeBlockTab value="npm">
        ```bash
        npm install @xingxingmofashu/ui
        ```
      </CodeBlockTab>
      <CodeBlockTab value="bun">
        ```bash
        bun add @xingxingmofashu/ui
        ```
      </CodeBlockTab>
    </CodeBlockTabs>
  </Step>
  <Step>
    #### 引入包样式

    ```css [app.css]
    @import "tailwindcss";
    @import "@xingxingmofashu/ui";
    ```

    包根会通过 `style` 导出解析到 `dist/index.css`。样式表自带 Tailwind 扫描规则，无需额外添加 `@source`。
  </Step>
  <Step>
    #### 导入组件

    ```tsx
    import { Button } from "@xingxingmofashu/ui";

    export function Example() {
      return <Button label="继续" />;
    }
    ```

    <Callout type="idea" title="提示">
    单个组件与主题配方支持深层导入：

    ```tsx
    import { Button } from "@xingxingmofashu/ui/components/button";
    import buttonTheme from "@xingxingmofashu/ui/theme/button";
    ```
    </Callout>
  </Step>
</Steps>

## 环境要求

- Node.js 22 或更高版本。
- React 与 React DOM 19。
- Tailwind CSS 4。
- 支持 ESM 的打包器。包只发布 ES 模块。
- 支持 `backdrop-filter`、`color-mix`、容器单位与 `:has` 的现代浏览器。

`Card` 可以从 React Server Component 渲染；交互组件是客户端组件。

## 主题

明暗 token 通过 `.light` / `.dark` 或 `data-theme="light"` / `data-theme="dark"` 切换：

```html [index.html]
<html class="dark">
```

或：

```html [index.html]
<html data-theme="dark">
```

嵌套的 `.light` / `[data-theme="light"]` 子树可以切回浅色 token。共享颜色与玻璃参数位于 `--ui-*` token 中，可在自己的主题层覆盖。Tailwind 别名使用 `ui-` 前缀（`text-ui-ink`、`outline-ui-glass-focus` 等），避免与宿主项目的 token 冲突。

## 常见问题

<Accordions>
  <Accordion title="样式没有生效">
    确认包样式与 Tailwind 从同一个 CSS 入口引入：

    ```css [app.css]
    @import "tailwindcss";
    @import "@xingxingmofashu/ui";
    ```

    包样式表会扫描 `dist` 中的组件文件，因此不需要手动添加 `@source`。
  </Accordion>
  <Accordion title="React 18">
    组件库面向 React 19。安装 `@xingxingmofashu/ui` 前，请先升级 `react` 与 `react-dom`。
  </Accordion>
</Accordions>

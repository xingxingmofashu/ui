---
title: "安装"
description: "安装 Liquid Glass UI，并在 Tailwind CSS 入口引入玻璃样式。"
---

需要 Node.js 22+、React 19 与 Tailwind CSS 4。

```bash
pnpm add @xingxingmofashu/ui
```

包以 `latest` 标签发布。

在 Tailwind CSS 入口文件中引入包样式：

```css
@import "tailwindcss";
@import "@xingxingmofashu/ui";
```

包根会通过 `style` 导出解析到 `dist/index.css`。样式表自带 Tailwind 扫描规则，无需额外添加 `@source`。

然后从包根导入组件：

```tsx
import { Button } from "@xingxingmofashu/ui";

export function Example() {
  return <Button label="继续" />;
}
```

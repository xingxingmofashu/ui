---
title: "Tabs"
description: "可访问的 React 标签页组件，采用 Liquid Glass 标签栏、滑动指示器，并支持键盘导航。"
---

`Tabs` 用于在同一页面的一组相关面板之间切换。标签栏共享一块玻璃表面，半透明指示器会跟随当前标签移动。

标签页通过 `items` 数组传入。每个条目的 `value` 会把标签按钮与对应面板关联起来，`content` 则渲染在该面板中。非受控用法使用 `defaultValue`，受控用法使用 `value` 与 `onValueChange`。

## 基础示例

标签按钮可以同时包含文字与图标。默认会激活第一个可用的标签。

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。标签高度、内边距、文字、图标、间距与面板文字会一起缩放。

<Example name="tabs/sizes" />

## 受控用法

`value` 与 `onValueChange` 让当前标签完全由外部状态控制。把 `value` 设为 `null` 可以渲染没有激活标签的状态。

<Example name="tabs/controlled" />

## 纵向布局

使用 `orientation="vertical"` 切换为左右布局。方向键会跟随方向变化，因此纵向标签使用 `ArrowDown` 与 `ArrowUp` 移动。

<Example name="tabs/vertical" />

## 禁用标签

在组件上设置 `disabled` 会禁用所有标签；在单个 item 上设置 `disabled` 只会禁用该标签。禁用标签仍然可见，并保留在标签栏中。

## API reference

**Tabs**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly TabsItemProps[]` | — | 组件渲染的标签与面板。 |
| `value` | `string \| null` | — | 受控的当前值。设为 `null` 时不激活任何标签。 |
| `defaultValue` | `string \| null` | 第一个可用项 | 非受控时的初始值。 |
| `onValueChange` | `(value: string, details) => void` | — | 当前值变化时调用。 |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | 布局与键盘方向。 |
| `activateOnFocus` | `boolean` | `false` | 方向键移动焦点时是否立即激活标签。 |
| `loopFocus` | `boolean` | `true` | 焦点到达末尾后是否回到第一个标签。 |
| `disabled` | `boolean` | `false` | 禁用所有标签。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 标签高度、内边距、文字、图标与间距。 |
| `aria-label` | `string` | — | 标签栏的无障碍名称。 |
| `aria-labelledby` | `string` | — | 用外部元素命名标签栏。 |
| `aria-describedby` | `string` | — | 外部说明文字的 ID。 |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | — | 替换根元素。 |
| `ref` | `Ref<HTMLDivElement>` | — | 转发到根元素的 ref。 |
| `className` | `string` | — | 合并到根元素的 Tailwind 类名。 |
| `ui` | `{ root?: ClassValue; list?: ClassValue; glass?: ClassValue; overlay?: ClassValue; indicator?: ClassValue; tab?: ClassValue; icon?: ClassValue; label?: ClassValue; panels?: ClassValue; panel?: ClassValue; panelContent?: ClassValue }` | — | 按 `data-slot` 组织的内部槽位类名。 |

**TabsItem**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | 关联标签与面板的值。 |
| `label` | `ReactNode` | — | 标签内的可见文字。 |
| `icon` | `ReactNode` | — | 文字前的装饰性图标。 |
| `content` | `ReactNode` | — | 标签激活时显示的面板内容。 |
| `keepMounted` | `boolean` | `false` | 其他标签激活时是否保留面板 DOM。 |
| `disabled` | `boolean` | `false` | 禁用该标签。 |
| `aria-label` | `string` | — | 仅图标标签的无障碍名称。 |
| `aria-labelledby` | `string` | — | 用外部元素命名仅图标标签。 |
| `nativeButton` | `boolean` | `true` | 标签是否渲染原生 `<button>`。 |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | — | 替换标签元素。 |
| `ref` | `Ref<HTMLElement>` | — | 转发到标签元素的 ref。 |
| `className` | `string` | — | 合并到标签按钮的 Tailwind 类名；面板请使用 `ui.panel`。 |
| `ui` | `{ tab?: ClassValue; icon?: ClassValue; label?: ClassValue; panel?: ClassValue; panelContent?: ClassValue }` | — | 按 `data-slot` 组织的该标签内部槽位类名。 |

根 `ui` 会先合并到每个标签与面板，再合并该 item 的 `ui`，最后合并 item 的 `className`。

| Attribute | Description |
| --- | --- |
| `data-active` | 标签处于激活状态时存在。 |
| `data-disabled` | 组件或标签禁用时存在。 |
| `data-orientation` | 表示方向（`horizontal` 或 `vertical`）。 |
| `data-activation-direction` | 表示新激活标签相对上一个标签的方向。 |
| `data-hidden` | 面板已挂载但未激活时存在。 |
| `data-starting-style` | 面板开始进入动画时存在。 |
| `data-ending-style` | 面板退出动画时存在。 |
| `data-slot` | 标记内部部件（`root`、`list`、`glass`、`overlay`、`indicator`、`tab`、`icon`、`label`、`panels`、`panel`、`panel-content`）。 |

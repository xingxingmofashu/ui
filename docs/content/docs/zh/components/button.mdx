## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 按钮文字。与 `children` 同时提供时优先使用 `label`。 |
| `children` | `ReactNode` | — | `label` 未提供时使用的可见内容。 |
| `leadingIcon` | `ReactNode` | — | 标签前的图标。 |
| `trailingIcon` | `ReactNode` | — | 标签后的图标，使用与前置图标相同的容器。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制高度、内边距和图标尺寸。 |
| `className` | `string \| ((state: { disabled: boolean }) => string \| undefined)` | — | 合并到外层 `root`。回调会收到 Base UI 的按钮状态。 |
| `style` | `CSSProperties \| ((state: { disabled: boolean }) => CSSProperties \| undefined)` | — | 透传给底层 Base UI `Button`。 |
| `ui` | `Partial<Record<ButtonThemeSlot, string>>` | — | 覆盖内部 Slot 样式。 |

其余属性会透传给 Base UI 的 `Button`，包括 `disabled`、`focusableWhenDisabled`、`nativeButton`、`onClick`、`type`、`render` 和 `ref`。

### UI Slots

| Slot | 说明 |
| --- | --- |
| `root` | 外层点击区域。 |
| `base` | 布局、hover 位移与按压缩放。 |
| `glass` | 可见的玻璃胶囊，承载共享玻璃材质。 |
| `label` | 文字容器。 |
| `leadingIcon` | 前置图标容器。 |
| `trailingIcon` | 后置图标容器。 |
| `overlay` | 玻璃边缘高光层。 |

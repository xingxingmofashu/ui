## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。文字和图标会随尺寸缩放，不需要给图标单独传 `size`。

<Example name="button/sizes" />

## 图标

前置图标位于文字左侧，后置图标位于文字右侧。两个图标使用相同的普通容器。

<Example name="button/icons" />

## 状态

禁用状态使用原生 `disabled`，键盘与指针交互都会停止。`focusableWhenDisabled` 会让按钮在禁用时仍保留在 Tab 顺序中，组件通过 `aria-disabled` 表达禁用状态并阻止激活，适合需要提示原因的禁用操作。

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 按钮文字；与 `children` 同时提供时优先使用 `label`。 |
| `children` | `ReactNode` | — | `label` 未提供时使用的可见内容。 |
| `leadingIcon` | `ReactNode` | — | 标签前的装饰性图标。 |
| `trailingIcon` | `ReactNode` | — | 标签后的装饰性图标。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制高度、内边距、文字与图标尺寸。 |
| `disabled` | `boolean` | `false` | 禁用按钮。 |
| `focusableWhenDisabled` | `boolean` | `false` | 禁用时仍保留在 Tab 顺序中，并通过 `aria-disabled` 表达状态。 |
| `nativeButton` | `boolean` | `true` | 是否渲染原生 `<button>`；渲染链接或其他元素时设为 `false`。 |
| `type` | `"button" \| "submit" \| "reset"` | — | 原生按钮类型。 |
| `form` | `string` | — | 拥有该按钮的表单 ID。 |
| `name` | `string` | — | 随表单提交的字段名。 |
| `value` | `string` | — | 随表单提交的值。 |
| `onClick` | `MouseEventHandler<HTMLElement>` | — | 按钮被按下时调用。 |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | — | 替换渲染的元素。 |
| `ref` | `Ref<HTMLElement>` | — | 转发到渲染元素的 ref。 |
| `className` | `string` | — | Tailwind 类名，合并到外层 `root`。 |
| `ui` | `{ root?: ClassValue; base?: ClassValue; glass?: ClassValue; overlay?: ClassValue; label?: ClassValue; leadingIcon?: ClassValue; trailingIcon?: ClassValue }` | — | 按 `data-slot` 组织的内部槽位类名。 |

| Attribute | Description |
| --- | --- |
| `data-disabled` | 按钮禁用时存在。 |
| `data-slot` | 标记内部部件（`root`、`base`、`glass`、`overlay`、`leading-icon`、`label`、`trailing-icon`），用于样式选择。 |

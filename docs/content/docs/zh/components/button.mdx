## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 按钮文字。与 `children` 同时提供时优先使用 `label`。 |
| `children` | `ReactNode` | — | `label` 未提供时使用的可见内容。 |
| `leadingIcon` | `ReactNode` | — | 标签前的图标。 |
| `trailingIcon` | `ReactNode` | — | 标签后的图标，使用与前置图标相同的容器。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制高度、内边距和图标尺寸。 |
| `className` | `any` | — | Tailwind 类名，合并到外层 `root`。 |

其余属性会透传给 Base UI 的 `Button`，包括 `disabled`、`focusableWhenDisabled`、`nativeButton`、`onClick`、`type`、`render` 和 `ref`。

`style` 被有意禁用：玻璃主题接管表面与 Base UI 元素本身。布局请使用 `className`。玻璃材质由组件内部维护，不支持按按钮自定义；如需调整，请修改共享的 `--ui-glass-*` tokens。

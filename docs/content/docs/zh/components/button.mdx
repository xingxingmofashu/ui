## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。文字和图标会随尺寸缩放，不需要给图标单独传 `size`。

<Example name="button/sizes" />

## 图标

前置图标位于文字左侧，后置图标位于文字右侧。两个图标使用相同的普通容器。

<Example name="button/icons" />

## 状态

禁用状态使用原生 `disabled`，键盘与指针交互都会停止。`focusableWhenDisabled` 会让按钮在禁用时仍保留在 Tab 顺序中，Base UI 通过 `aria-disabled` 表达禁用状态并阻止激活，适合需要提示原因的禁用操作。

<Example name="button/states" />

其余属性会透传给 Base UI 的 `Button`，包括 `disabled`、`focusableWhenDisabled`、`nativeButton`、`onClick`、`type`、`render` 和 `ref`。

`style` 被有意禁用：玻璃主题接管表面与 Base UI 元素本身。布局请使用 `className`。玻璃材质由组件内部维护，不支持按按钮自定义；如需调整，请修改共享的 `--ui-glass-*` tokens。

`Button` 渲染带 Liquid Glass 表面的原生按钮，支持可选的前后图标与五种尺寸。它用于触发操作；需要导航时，可将其渲染为链接。

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。文字和图标会随尺寸缩放，不需要给图标单独传 `size`。

<Example name="button/sizes" />

## 图标

前置图标位于内容左侧，后置图标位于内容右侧。两个图标使用相同的普通容器。纯图标按钮需要提供 `aria-label`；没有内容时不会渲染空的 label 插槽，图标会保持居中。

<Example name="button/icons" />

## 状态

禁用状态使用原生 `disabled`，键盘与指针交互都会停止。`focusableWhenDisabled` 会让按钮在禁用时仍保留在 Tab 顺序中，组件通过 `aria-disabled` 表达禁用状态并阻止激活，适合需要提示原因的禁用操作。

## 无障碍

`Button` 默认渲染原生 `<button>`，因此焦点、`Enter` 与 `Space` 激活以及禁用行为都由平台提供。可见内容提供可访问名称。纯图标按钮必须使用 `aria-label` 或 `aria-labelledby`；图标插槽是装饰性的，对辅助技术隐藏。

使用 `nativeButton={false}` 渲染链接或其他元素时，请保持可见内容有意义，并选择与操作语义匹配的元素。`focusableWhenDisabled` 会让禁用的操作保留在 Tab 顺序中，通过 `aria-disabled` 暴露状态，同时阻止激活。

## API 参考

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 按钮可见内容；未设置 ARIA 名称时同时作为可访问名称。 |
| `leadingIcon` | `ReactNode` | — | 内容前的装饰性图标。 |
| `trailingIcon` | `ReactNode` | — | 内容后的装饰性图标。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制高度、内边距、文字与图标尺寸。 |
| `focusableWhenDisabled` | `boolean` | `false` | 禁用时仍保留在 Tab 顺序中，并通过 `aria-disabled` 表达状态。 |
| `nativeButton` | `boolean` | `true` | `Button` 渲染的根元素是否为原生 `<button>`；`render` 渲染 `<div>` 等其他元素时设为 `false`。 |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | — | 替换根元素，或与其他组件组合。 |
| `className` | `ClassValue` | — | Tailwind 类名，合并到外层 `root`。 |
| `style` | `CSSProperties` | — | 内联样式，合并到与 `className` 相同的元素。 |
| `ui` | `{ root?: ClassValue; base?: ClassValue; glass?: ClassValue; overlay?: ClassValue; label?: ClassValue; leadingIcon?: ClassValue; trailingIcon?: ClassValue }` | — | 按 `data-slot` 组织的内部槽位类名。 |

原生 `<button>` 属性（如 `disabled`、`type`、`form`、`name`、`value`、`onClick`、`aria-*`）以及 `ref` 会透传到渲染元素。可见内容通过 `children` 传入。

| 属性 | 说明 |
| --- | --- |
| `data-disabled` | 按钮禁用时存在。 |
| `data-slot` | 标记内部部件（`root`、`base`、`glass`、`overlay`、`leading-icon`、`label`、`trailing-icon`），用于样式选择。纯图标按钮不会渲染 `label`。 |

## 主题

组件使用共享玻璃材质。可以在父级调整 `--ui-glass-*` token，用 `className` 控制布局，并通过 `ui` 按 `data-slot` 调整内部槽位。组件级数值位于 `src/theme/button.ts`。Token 分层与预设见[主题指南](/docs/zh/guides/theming)。

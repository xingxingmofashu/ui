## 基础示例

下面的视图切换使用真实 Toggle Group。选中项会显示 Liquid Glass 选中态，并把当前值同步到下方文字。

选项通过 `items` 数组传入，每个条目的 `value` 对应 group 的选中值。

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。

<Example name="toggle-group/sizes" />

## 选择模式

使用 `multiple` 允许多个 item 同时选中，默认是单选。

<Example name="toggle-group/selection" />

## 方向

使用 `orientation="vertical"` 切换为纵向布局：

<Example name="toggle-group/orientation" />

## 受控用法

`value` 与 `onValueChange` 让选中值完全由外部状态控制。下面的示例在清空后仍然保持受控：

## 禁用

在 group 上设置 `disabled` 会禁用所有 item；在单个 item 上设置 `disabled` 只会禁用该选项。

<TypeTable
  type={{

`ToggleGroup` 还会透传 Base UI `ToggleGroup` 的 `loopFocus`、`render`、`ref` 等属性。

`style` 被有意禁用：玻璃主题接管表面与 Base UI 元素本身。布局请使用 `className`。

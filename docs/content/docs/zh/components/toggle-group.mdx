## Props

### ToggleGroup

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `readonly string[]` | — | 受控的选中值。 |
| `defaultValue` | `readonly string[]` | — | 初始选中值。 |
| `onValueChange` | `(value: string[], details) => void` | — | 选中值变化时调用。 |
| `multiple` | `boolean` | `false` | 是否允许多选。 |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | 布局和键盘方向。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制 item 高度、内边距、文字和图标尺寸。 |
| `disabled` | `boolean` | `false` | 禁用所有 item。 |
| `items` | `readonly ToggleGroupItemProps[]` | — | 渲染在 group 内部的选项。 |
| `className` | `any` | — | Tailwind 类名，合并到 group root。 |

`ToggleGroup` 还会透传 Base UI `ToggleGroup` 的 `loopFocus`、`render`、`ref` 等属性。

`style` 被有意禁用：玻璃主题接管表面与 Base UI 元素本身。布局请使用 `className`。

### Item 条目

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | — | group value 使用的必填标识。 |
| `label` | `ReactNode` | — | item 内的可见文字。 |
| `icon` | `ReactNode` | — | 文字前的图标。 |
| `aria-label` | `string` | — | 仅图标时使用的无障碍名称。 |
| `aria-labelledby` | `string` | — | 用外部元素命名仅图标 item。 |
| `disabled` | `boolean` | `false` | 禁用该项。 |
| `className` | `string` | — | 合并到 item root。 |

Item 条目是普通对象；toggle group 会在内部渲染 Base UI 的 toggle。

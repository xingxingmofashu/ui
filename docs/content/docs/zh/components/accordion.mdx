## 基础示例

每个 item 都会渲染真实的标题与按钮。默认的加号指示器会旋转成关闭图标，面板高度平滑过渡。

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。触发器高度、内边距、文字与指示器会一起缩放。

## Props

### Accordion

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string[]` | — | 受控的展开值。 |
| `defaultValue` | `string[]` | `[]` | 初始展开值。 |
| `onValueChange` | `(value: string[], details) => void` | — | 展开值变化时调用。 |
| `multiple` | `boolean` | `false` | 是否允许多个面板同时展开。 |
| `disabled` | `boolean` | `false` | 禁用所有触发器。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制触发器高度、内边距、文字与指示器尺寸。 |
| `headingAs` | `"h1" \| "h2" \| "h3" \| "h4" \| "h5" \| "h6"` | `"h3"` | 包裹每个触发器的标题元素。 |
| `hiddenUntilFound` | `boolean` | `false` | 使用 `hidden="until-found"` 保留关闭的面板，让浏览器页内查找可以展开匹配内容。 |
| `keepMounted` | `boolean` | `false` | 关闭时仍保留面板 DOM。 |
| `className` | `string \| ((state) => string \| undefined)` | — | 合并到 root。回调会收到 Base UI 状态。 |
| `ui` | `AccordionStyle` | — | 覆盖 root 图层样式。 |

`Accordion` 还会透传 Base UI `Accordion.Root` 的 `render`、`ref`、`onValueChange` 等属性。

`style` 被有意禁用：玻璃主题接管表面与 Base UI 元素本身。布局请使用 `className`，主题扩展请使用 `ui` 槽位。

### AccordionItem

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | — | accordion value 使用的必填标识。 |
| `title` | `ReactNode` | — | 触发器内的可见标题。 |
| `children` | `ReactNode` | — | 面板内容。 |
| `disabled` | `boolean` | `false` | 禁用该 item。 |
| `onOpenChange` | `(open: boolean, details) => void` | — | 该面板展开或收起时调用。 |
| `indicator` | `ReactNode` | — | 替换默认的加号指示器。 |
| `className` | `string \| ((state) => string \| undefined)` | — | 合并到 item root。回调会收到 Base UI item 状态。 |
| `ui` | `AccordionItemStyle` | — | 覆盖 item 内部 Slot 样式。 |

`AccordionItem` 还会透传 Base UI `Accordion.Item` 的 `render`、`ref` 等属性。

item 上同样有意禁用 `style`；请使用 `className` 或 `ui` 槽位。

| `AccordionItem` | `indicator` | 圆形玻璃指示器。 |

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。触发器高度、内边距、文字与指示器会一起缩放。

## Props

### Accordion

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string[]` | — | 受控的展开值。 |
| `defaultValue` | `string[]` | `[]` | 初始展开值。 |
| `onValueChange` | `(value: string[], details) => void` | — | 展开值变化时调用。 |
| `multiple` | `boolean` | `false` | 是否允许多个面板同时展开。 |
| `disabled` | `boolean` | `false` | 禁用所有触发器。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制触发器高度、内边距、文字与指示器尺寸。 |
| `items` | `readonly AccordionItemProps[]` | — | 渲染在 accordion 内部的面板。 |
| `hiddenUntilFound` | `boolean` | `false` | 使用 `hidden="until-found"` 保留关闭的面板，让浏览器页内查找可以展开匹配内容。 |
| `keepMounted` | `boolean` | `false` | 关闭时仍保留面板 DOM。 |
| `className` | `any` | — | 合并到 root。 |

`Accordion` 还会透传 Base UI `Accordion.Root` 的 `render`、`ref` 等属性。

`style` 被有意禁用：玻璃主题接管表面与 Base UI 元素本身。布局请使用 `className`。Accordion 的样式属于内部实现，不支持逐实例修改；请通过共享的 `--ui-glass-*` token 调整。

### Item 条目

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | — | accordion value 使用的必填标识。 |
| `title` | `ReactNode` | — | 触发器内的可见标题。 |
| `content` | `ReactNode` | — | 面板内容。 |
| `disabled` | `boolean` | `false` | 禁用该 item。 |
| `onOpenChange` | `(open: boolean, details) => void` | — | 该面板展开或收起时调用。 |
| `className` | `any` | — | 合并到 item root。 |

Item 条目是普通对象；accordion 会在内部渲染 Base UI 的 item、header、trigger 与 panel。

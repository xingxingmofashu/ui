## 基础示例

每个 `items` 条目都会渲染真实的标题与按钮。默认的加号指示器会旋转成关闭图标，面板高度平滑过渡。

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。触发器高度、内边距、文字与指示器会一起缩放。

在根上设置 `disabled` 会禁用所有触发器；在单个 item 上设置 `disabled` 只会禁用该面板。

## API reference

**Accordion**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string[]` | — | 受控的展开值。 |
| `defaultValue` | `string[]` | `[]` | 初始展开值。 |
| `onValueChange` | `(value: string[], details) => void` | — | 展开值变化时调用。 |
| `multiple` | `boolean` | `false` | 是否允许多个面板同时展开。 |
| `disabled` | `boolean` | `false` | 禁用所有触发器。 |
| `hiddenUntilFound` | `boolean` | `false` | 使用 `hidden="until-found"` 保留关闭的面板，让浏览器页内查找可以展开匹配内容。 |
| `keepMounted` | `boolean` | `false` | 关闭时仍保留面板 DOM。 |
| `loopFocus` | `boolean` | — | 已废弃，不再影响键盘焦点。 |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` | 已废弃，不再影响键盘焦点。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制触发器高度、内边距、文字与指示器尺寸。 |
| `items` | `readonly AccordionItemProps[]` | — | 渲染在 accordion 内部的面板。 |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | — | 替换根元素。 |
| `ref` | `Ref<HTMLDivElement>` | — | 转发到根元素的 ref。 |
| `className` | `string` | — | 合并到根元素的 Tailwind 类名。 |

**AccordionItem**

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | 必填，accordion value 使用的标识。 |
| `title` | `ReactNode` | — | 必填，触发器内的可见标题。 |
| `content` | `ReactNode` | — | 面板内容。 |
| `disabled` | `boolean` | `false` | 禁用该 item。 |
| `onOpenChange` | `(open: boolean, details) => void` | — | 该面板展开或收起时调用。 |
| `className` | `string` | — | 合并到 item root 的 Tailwind 类名。 |

| Attribute | Description |
| --- | --- |
| `data-disabled` | accordion 或 item 被禁用时存在。 |
| `data-orientation` | 表示方向（`horizontal` 或 `vertical`）。 |
| `data-index` | 在 item 与 trigger 上表示 item 索引。 |
| `data-open` | item 展开时存在。 |
| `data-panel-open` | 触发器的面板展开时存在。 |
| `data-starting-style` | 面板开始进入动画时存在。 |
| `data-ending-style` | 面板正在退出动画时存在。 |

## 基础示例

每个 `items` 条目都会渲染真实的标题与按钮。默认的加号指示器会旋转成关闭图标，面板高度平滑过渡。

<Example name="accordion/basic" />

## 多面板展开

默认只保留一个展开的面板。添加 `multiple` 可以让多个面板同时展开：

<Example name="accordion/multiple" />

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。触发器高度、内边距、文字与指示器会一起缩放。

<Example name="accordion/sizes" />

## 受控用法

`value` 与 `onValueChange` 让展开状态完全由外部控制。下面的示例可以通过一个按钮展开或收起全部面板：

<Example name="accordion/controlled" />

## 禁用

在根上设置 `disabled` 会禁用所有触发器；在单个 item 上设置 `disabled` 只会禁用该面板。

`Accordion` 还会透传 Base UI `Accordion.Root` 的 `render`、`ref` 等属性。

`style` 被有意禁用：玻璃主题接管表面与 Base UI 元素本身。布局请使用 `className`。Accordion 的样式属于内部实现，不支持逐实例修改；请通过共享的 `--ui-glass-*` token 调整。

## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 可见标签。 |
| `description` | `ReactNode` | — | 辅助说明。 |
| `showValue` | `boolean` | `false` | 在 header 中渲染当前值或区间。 |
| `value` | `number \| readonly number[]` | — | 受控值；数组会渲染多个滑块。 |
| `defaultValue` | `number \| readonly number[]` | — | 非受控初始值。 |
| `onValueChange` | `(value, details) => void` | — | 值变化时触发。 |
| `min` | `number` | `0` | 最小值。 |
| `max` | `number` | `100` | 最大值。 |
| `step` | `number` | `1` | 方向键和拖动的步进。 |
| `largeStep` | `number` | `10` | Page Up / Page Down 与 Shift + 方向键的步进。 |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | 布局与键盘方向。 |
| `format` | `Intl.NumberFormatOptions` | — | 数值显示格式。 |
| `locale` | `Intl.LocalesArgument` | — | 数值格式化使用的 locale。 |
| `disabled` | `boolean` | `false` | 禁用滑块。 |
| `name` | `string` | — | 表单提交时使用的字段名。 |
| `className` | `string \| ((state) => string \| undefined)` | — | 合并到最外层 `root`。回调会收到 Base UI slider 状态。 |
| `style` | `CSSProperties \| ((state) => CSSProperties \| undefined)` | — | 合并到 `root` 的内联样式。回调会收到 Base UI slider 状态。 |
| `ui` | `Partial<Record<SliderThemeSlot, string>>` | — | 覆盖内部 Slot 样式。 |

其余属性会透传给 Base UI 的 `Slider.Root`，包括 `form`、`name`、`thumbAlignment`、`thumbCollisionBehavior`、`render` 和 `ref`。

### UI Slots

| Slot | 说明 |
| --- | --- |
| `root` | 最外层容器，包含标签、轨道和说明。 |
| `header` | 标签与数值显示区域。 |
| `label` | 可见标签。 |
| `value` | 当前值或区间。 |
| `description` | 辅助说明。 |
| `control` | 轨道与滑块的交互容器。 |
| `track` | 滑块轨道。 |
| `indicator` | 已选区间填充条。 |
| `thumb` | 液态玻璃滑块。 |

---
title: "Slider"
description: "可访问的 React 滑块，采用 Liquid Glass 轨道，支持单值、区间与纵向布局。"
---

`Slider` 是 Base UI `Slider.Root` 的样式封装，内部渲染 control、track、indicator 和玻璃 thumb。属性会透传给 `Slider.Root`；`style` 与 `children` 不支持。

## 基础示例

下面的滑块直接渲染真实组件。标签和数值由外部渲染；拖动滑块、点击轨道或使用方向键都会更新数值。

## 可访问名称

Slider 不渲染可见标签。请用 `aria-labelledby` 指向外部可见标签；Base UI 会把它从 root 转发给每个 thumb。`aria-label` 与 `aria-describedby` 只保留在 root 上。

## 区间值

传入数组会为每个值渲染一个 thumb。`format` 使用 `Intl.NumberFormatOptions`，并应用到 thumb 的可访问数值文本。

`ref` 会转发到 root，其余原生属性也会透传。

`style` 被有意禁用：玻璃主题接管表面与 Base UI 元素本身。布局请使用 `className`。滑块样式由组件内部维护，不支持按实例自定义；如需调整，请修改共享的 `--ui-glass-*` tokens。

title: "Input"
description: "可访问的 React 输入框，采用 Liquid Glass 字段、标签、说明文字与图标插槽。"
---

`Input` 封装 Base UI 的 `Input`，渲染玻璃质感的输入区域、原生 `<input>`、可选标签与说明文字，以及可选的前后图标。

可见标签是真实的 `<label>`，会自动与输入框关联。传入 `description` 时，说明文字会获得 id，输入框通过 `aria-describedby` 指向它；你传入的 `aria-describedby` 会与它合并。

## 基础示例

使用 `value` + `onValueChange` 创建受控输入框，或使用 `defaultValue` 创建非受控输入框。`type`、`name`、`placeholder`、`required`、`readOnly` 等原生输入属性都会透传。

## 尺寸

提供 `xs`、`sm`、`md`、`lg`、`xl` 五种尺寸；高度、内边距、圆角、文字与图标尺寸会同步缩放。

<Example name="input/sizes" />

## 图标

`leadingIcon` 渲染在输入框前方，`trailingIcon` 渲染在后方。两个插槽都是装饰性的，会带有 `aria-hidden="true"`；可访问名称请使用 `label` 或 `aria-label`。

<Example name="input/icons" />

## 状态

`disabled` 会透传给原生输入框，并淡化整个字段。`readOnly` 保留焦点与文本选择能力，但阻止修改。

其余属性会透传给 Base UI 的 `Input`，包括 `value`、`defaultValue`、`onValueChange`、`type`、`placeholder`、`name`、`id`、`disabled`、`readOnly`、`required` 和 `ref`。

没有可见 `label` 时，请自行提供 `aria-label` 或 `aria-labelledby`。可见 `description` 会被自动朗读；如果还需要自己的 `aria-describedby`，两个引用会合并。

`style` 被有意禁用：玻璃主题接管输入区域的外观。布局请使用 `className`，主题调整请通过共享的 `--ui-*` tokens 完成。

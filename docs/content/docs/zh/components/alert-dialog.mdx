`AlertDialog` 是 Base UI `AlertDialog` 的一体化封装。它内部渲染 Portal、遮罩、居中弹窗、标题、描述、可选正文以及固定的取消/确认操作。

## 基础示例

组件完全受控：用 `open` 控制显示，触发按钮由页面自己渲染。它是模态的，点击遮罩不会关闭，用户必须选择一个操作。

<Example name="alert-dialog/basic" />

## 受控用法

`open` 与 `onOpenChange` 控制对话框。自己渲染按钮并把 `open` 设为 `true` 即可打开；`onConfirm` 与 `onCancel` 用于执行操作副作用。

## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | 对话框标题。 |
| `description` | `ReactNode` | — | 标题下方的说明文字。 |
| `children` | `ReactNode` | — | 描述与操作按钮之间的额外内容。 |
| `cancelLabel` | `ReactNode` | `"Cancel"` | 取消按钮文案。 |
| `confirmLabel` | `ReactNode` | `"Confirm"` | 确认按钮文案。 |
| `onCancel` | `MouseEventHandler<HTMLButtonElement>` | — | 点击取消时调用。 |
| `onConfirm` | `MouseEventHandler<HTMLButtonElement>` | — | 点击确认时调用。 |
| `open` | `boolean` | — | 受控的打开状态。 |
| `defaultOpen` | `boolean` | `false` | 非受控时的初始打开状态。 |
| `onOpenChange` | `(open: boolean, details) => void` | — | 对话框打开或关闭时调用。 |
| `onOpenChangeComplete` | `(open: boolean) => void` | — | 打开或关闭动画结束后调用。 |
| `className` | `any` | — | 合并到弹窗的 Tailwind 类名。 |

`AlertDialog` 还会透传 Base UI `AlertDialog.Root` 的 `actionsRef`、`handle`、`triggerId`、`defaultTriggerId` 等属性。

`style` 被有意禁用：玻璃主题接管遮罩、弹窗与内容。布局请使用 `className`。对话框样式属于内部实现，不支持逐实例修改；请通过共享的 `--ui-glass-*` token 调整。

操作区固定为取消与确认两个按钮，并使用包内的 `Button`。受控模式下请通过 `onOpenChange` 更新 `open`。

Base UI 负责 `alertdialog` 角色、由标题生成 `aria-labelledby`、由描述生成 `aria-describedby`、焦点锁定、滚动锁定以及关闭后的焦点恢复。

title: "Toolbar"

---

`Toolbar` 渲染一条玻璃操作栏，内部可以包含操作按钮、切换按钮、链接、分组与分隔线。它适合编辑器控件、格式工具栏，以及需要共享同一个键盘停靠点的紧凑操作行。条目通过 `items` 传入，方向键用于在栏内移动焦点。

## 用法

### Items

`items` 接受操作按钮、切换按钮、链接、分组与分隔线。普通按钮条目不需要 `kind`；通过 `label`、`icon` 以及 `onClick`、`disabled` 等原生按钮属性配置。只有图标的按钮需要单独提供 `aria-label`，因为图标是装饰性的。

使用 `{ kind: "separator" }` 添加分隔线。分隔线默认采用与工具栏相反的方向，因此在水平工具栏中显示为竖线。

<Example name="toolbar/basic" />

### Toggle

使用 `{ kind: "toggle" }` 表示双状态操作。传入 `pressed` 与 `onPressedChange` 可完全受控，或用 `defaultPressed` 设置非受控初始状态。按下的切换按钮会暴露 `aria-pressed`，并复用其他按下控件共用的玻璃滑块。

<Example name="toolbar/toggle" />

### Group

使用 `{ kind: "group" }` 表示一组相关的条目。分组通过自己的 `items` 数组接受操作按钮、切换按钮与链接。需要名称时，为分组提供 `aria-label` 或 `aria-labelledby`。

<Example name="toolbar/group" />

### Link

使用 `{ kind: "link" }` 表示导航。链接条目必须提供 `href`，并渲染为原生锚点，因此保留标准的链接行为。链接条目没有禁用状态，在禁用的工具栏或分组中仍保持可用。

<Example name="toolbar/link" />

### Orientation

`orientation` 同时控制布局与方向键所在的轴，默认值为 `"horizontal"`。下例把纵向工具栏放在它控制的数值旁边。

<Example name="toolbar/orientation" />

### Size

`xs`、`sm`、`md`、`lg` 与 `xl` 会改变条目高度、内边距、文字、图标与分隔线长度，默认值为 `md`。

<Example name="toolbar/size" />

### Disabled

在工具栏上设置 `disabled` 会禁用其中的按钮与切换按钮；在按钮、切换按钮或分组上设置则只影响该部分。链接条目不受影响，仍保持可用。禁用的条目默认仍保留在 roving focus 顺序中，方便键盘用户发现它们；在按钮或切换按钮上传入 `focusableWhenDisabled={false}` 可将其移出该导航。

## 无障碍

`Toolbar` 渲染带有 `aria-orientation` 的 `role="toolbar"`。请使用 `aria-label` 或 `aria-labelledby` 为它命名。整条工具栏在 Tab 顺序中只占一个停靠点：水平工具栏使用 `ArrowRight` 与 `ArrowLeft` 移动焦点，纵向工具栏使用 `ArrowDown` 与 `ArrowUp`。`loopFocus` 默认为 `true`，焦点会在两端循环。

切换条目暴露 `aria-pressed`。禁用的按钮与切换按钮保留 `aria-disabled`，除非将 `focusableWhenDisabled` 设为 `false`，否则它们仍可聚焦，但会跳过激活。分组渲染 `role="group"`，使用自身的 `aria-label` 或 `aria-labelledby` 命名。分隔线渲染 `role="separator"`，方向与工具栏相反。只有图标的条目需要通过 `aria-label` 或 `aria-labelledby` 提供可访问名称，图标槽位对辅助技术隐藏。链接条目是原生锚点，保留浏览器的链接语义；它们不受工具栏 `disabled` 影响，并保留在 roving focus 顺序中。

共享的焦点与键盘模式见[无障碍指南](/docs/zh/guides/accessibility)。

## API 参考

**Toolbar**

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly ToolbarItemProps[]` | — | 工具栏渲染的操作、切换按钮、链接、分组与分隔线。 |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | 布局与方向键所在的轴。 |
| `loopFocus` | `boolean` | `true` | 方向键越过最后一个条目时，将焦点循环到另一端。 |
| `disabled` | `boolean` | `false` | 禁用按钮、切换按钮与分组，同时让可聚焦条目保留在 roving focus 顺序中。链接不受影响。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制条目高度、内边距、文字、图标与分隔线长度。 |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | — | 替换工具栏根元素。 |
| `className` | `ClassValue` | — | 合并到工具栏根元素的 Tailwind 类名。 |
| `style` | `CSSProperties` | — | 与 `className` 合并到同一元素的内联样式。 |
| `ui` | `{ root?: ClassValue; glass?: ClassValue; overlay?: ClassValue; group?: ClassValue; item?: ClassValue; content?: ClassValue; icon?: ClassValue; label?: ClassValue; separator?: ClassValue }` | — | 按 `data-slot` 组织的内部槽位 Tailwind 类名。 |

原生 `<div>` 属性、`aria-*` 与 `ref` 会转发到工具栏根元素。

## 主题

组件使用共享玻璃材质。可在父级调整共享 `--ui-glass-*` token，用 `className` 控制布局，用 `ui` 按 `data-slot` 调整内部结构。组件专属值位于 `src/theme/toolbar.ts`：`--ui-toolbar-item-height`、`--ui-toolbar-item-px`、`--ui-toolbar-font-size`、`--ui-toolbar-icon-size`、`--ui-toolbar-item-gap`、`--ui-toolbar-padding`、`--ui-toolbar-gap`、`--ui-toolbar-group-gap`、`--ui-toolbar-vertical-radius` 与 `--ui-toolbar-separator-length`。悬停填充、按下滑块、边缘、阴影与分隔线颜色由 `--ui-ink` 混合生成。token 分层与预设见[主题指南](/docs/zh/guides/theming)。

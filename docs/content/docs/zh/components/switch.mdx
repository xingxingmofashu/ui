Base UI 的 `Switch.Root` 就是最外层元素。视觉轨道是内部的 `base` 槽位，整行（包括标签和描述）都可以点击。`label` 会通过 `aria-labelledby` 成为可访问名称；当控件有标签或显式名称时，`description` 会通过 `aria-describedby` 关联。显式传入的 `aria-label` 或 `aria-labelledby` 优先决定名称，显式传入的 `aria-describedby` 会与描述合并。只有 description 的控件会把描述作为名称，不再添加 `aria-describedby`。

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 可见标签；未提供 `aria-label` 或 `aria-labelledby` 时会成为可访问名称。 |
| `description` | `ReactNode` | — | 辅助说明；控件有名称时会通过 `aria-describedby` 关联。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制开关尺寸与文字大小。 |
| `checked` | `boolean` | — | 受控选中状态。 |
| `defaultChecked` | `boolean` | `false` | 非受控初始状态。 |
| `onCheckedChange` | `(checked: boolean, details) => void` | — | 选中状态变化时调用。 |
| `disabled` | `boolean` | `false` | 禁用开关。 |
| `readOnly` | `boolean` | `false` | 只读，不允许切换，但仍可聚焦。 |
| `required` | `boolean` | `false` | 表单提交前必须开启。 |
| `name` | `string` | — | 表单字段名。 |
| `form` | `string` | — | 拥有隐藏输入框的表单 ID。 |
| `value` | `string` | — | 开启时随表单提交的值。 |
| `uncheckedValue` | `string` | — | 关闭时随表单提交的值。 |
| `id` | `string` | — | 隐藏输入框的 ID。 |
| `inputRef` | `Ref<HTMLInputElement>` | — | 指向隐藏原生输入框的 ref。 |
| `nativeButton` | `boolean` | `false` | 是否渲染原生 `<button>`。 |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | — | 替换根元素。 |
| `ref` | `Ref<HTMLElement>` | — | 转发到根元素的 ref。 |
| `className` | `string` | — | Tailwind 类名，合并到 Base UI switch root。 |

| Attribute | Description |
| --- | --- |
| `data-checked` | 开关开启时存在。 |
| `data-unchecked` | 开关关闭时存在。 |
| `data-disabled` | 开关禁用时存在。 |
| `data-readonly` | 开关只读时存在。 |
| `data-required` | 开关必填时存在。 |
| `data-valid` | 开关有效时存在（位于 `Field.Root` 内）。 |
| `data-invalid` | 开关无效时存在（位于 `Field.Root` 内）。 |
| `data-touched` | 开关被触碰后存在（位于 `Field.Root` 内）。 |
| `data-dirty` | 开关值变化后存在（位于 `Field.Root` 内）。 |
| `data-filled` | 开关开启时存在（位于 `Field.Root` 内）。 |
| `data-focused` | 开关聚焦时存在（位于 `Field.Root` 内）。 |
| `data-animating` | thumb 过渡动画运行时存在。 |

## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 可见标签。 |
| `description` | `ReactNode` | — | 辅助说明。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制开关尺寸与文字大小。 |
| `checked` | `boolean` | — | 受控选中状态。 |
| `defaultChecked` | `boolean` | — | 非受控初始状态。 |
| `onCheckedChange` | `(checked: boolean, details) => void` | — | 选中状态变化时触发。 |
| `disabled` | `boolean` | `false` | 禁用开关。 |
| `readOnly` | `boolean` | `false` | 只读，不允许切换。 |
| `className` | `string` | — | 合并到最外层布局容器。 |
| `style` | `CSSProperties` | — | 内联样式，合并到最外层布局容器。 |
| `baseClassName` | `string \| ((state) => string \| undefined)` | — | 合并到 Base UI switch root。回调会收到 Base UI switch 状态。 |
| `baseStyle` | `CSSProperties \| ((state) => CSSProperties \| undefined)` | — | 合并到 Base UI switch root 的内联样式。回调会收到 Base UI switch 状态。 |
| `ui` | `Partial<Record<SwitchThemeSlot, string>>` | — | 覆盖内部 Slot 样式。 |

其余属性会透传给 Base UI 的 `Switch.Root`，包括 `required`、`name`、`form`、`value`、`uncheckedValue`、`inputRef`、`nativeButton`、`render` 和 `ref`。

### UI Slots

| Slot | 说明 |
| --- | --- |
| `root` | 最外层容器，包含开关与文字。 |
| `container` | 开关本身的布局容器。 |
| `base` | 开关轨道。 |
| `thumb` | 液态玻璃滑块。 |
| `wrapper` | 标签与描述的文字容器。 |
| `label` | 可见标签。 |
| `description` | 辅助说明。 |

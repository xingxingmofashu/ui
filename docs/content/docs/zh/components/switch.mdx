Base UI 的 `Switch.Root` 就是最外层元素。视觉轨道是内部的 `base` 槽位，整行（包括标签和描述）都可以点击。`label` 会通过 `aria-labelledby` 成为可访问名称；当控件有标签或显式名称时，`description` 会通过 `aria-describedby` 关联。显式传入的 `aria-label` 或 `aria-labelledby` 优先决定名称，显式传入的 `aria-describedby` 会与描述合并。只有 description 的控件会把描述作为名称，不再添加 `aria-describedby`。

其余属性会透传给 Base UI 的 `Switch.Root`，包括 `required`、`name`、`form`、`value`、`uncheckedValue`、`inputRef`、`nativeButton`、`render` 和 `ref`。

`style`、`baseStyle` 与 `baseClassName` 被有意禁用：玻璃主题接管根元素和所有 Base UI 部件。根元素布局请使用 `className`。

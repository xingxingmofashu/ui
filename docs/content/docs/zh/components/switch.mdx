## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 可见标签。 |
| `description` | `ReactNode` | — | 辅助说明。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制开关尺寸与文字大小。 |
| `checked` | `boolean` | — | 受控选中状态。 |
| `defaultChecked` | `boolean` | — | 非受控初始状态。 |
| `onCheckedChange` | `(checked: boolean, details) => void` | — | 选中状态变化时触发。 |
| `disabled` | `boolean` | `false` | 禁用开关。 |
| `readOnly` | `boolean` | `false` | 只读，不允许切换。 |
| `className` | `string` | — | Tailwind 类名，合并到 Base UI switch root。 |

其余属性会透传给 Base UI 的 `Switch.Root`，包括 `required`、`name`、`form`、`value`、`uncheckedValue`、`inputRef`、`nativeButton`、`render` 和 `ref`。

`style`、`baseStyle` 与 `baseClassName` 被有意禁用：玻璃主题接管根元素和所有 Base UI 部件。根元素布局请使用 `className`。

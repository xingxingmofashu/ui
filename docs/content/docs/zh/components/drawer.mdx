---
title: "Drawer"
description: "从任意边缘滑入的 React 抽屉，采用 Liquid Glass 表面并支持手势关闭。"
---

`Drawer` 是 Base UI `Drawer` 的一体化封装。它内部渲染 Portal、遮罩、贴边弹窗、标题、描述、可选正文以及自定义操作区，并支持滑动关闭与可选吸附点。

与居中的 `Dialog` 不同，`Drawer` 从屏幕边缘滑入，适合移动端设置面板、筛选条件和侧边导航。

## 基础示例

默认从底部滑入。`open` 控制显示，`footer` 放置自己的按钮；按钮不会自动关闭抽屉，需要像示例一样更新 `open`。

<Example name="drawer/basic" />

## 侧边抽屉

`direction` 复用 Base UI `swipeDirection` 的取值：`down` 从底部滑入，`up` 从顶部滑入，`left` 和 `right` 从对应侧边滑入。默认 `down`，组件会同时调整弹窗位置、圆角、进入动画和滑动关闭方向。

<Example name="drawer/sides" />

## 手势关闭

触摸设备上可以朝 `direction` 对应的方向拖动抽屉来关闭；桌面端仍可使用遮罩、Esc 或操作区按钮。

<Example name="drawer/gesture" />

## 吸附点

`snapPoints`、`defaultSnapPoint`、`snapPoint`、`onSnapPointChange` 与 `snapToSequentialPoints` 会透传给 Base UI，可用于让底部或顶部抽屉在预设高度之间吸附。

<Example name="drawer/snap-points" />

## 禁止遮罩关闭

`disablePointerDismissal` 会阻止点击遮罩关闭抽屉，Esc 键和操作区按钮仍然可用；适合包含未保存内容的流程。

`Drawer` 还会透传 Base UI `Drawer.Root` 的 `actionsRef`、`handle`、`triggerId`、`defaultTriggerId`、`snapPoints`、`defaultSnapPoint`、`snapPoint`、`onSnapPointChange` 和 `snapToSequentialPoints`。

`style` 被有意禁用：玻璃主题接管遮罩、弹窗与内容。布局请使用 `className`。抽屉样式属于内部实现，不支持逐实例修改；请通过共享的 `--ui-glass-*` token 调整。

Base UI 负责 `dialog` 角色、由标题生成 `aria-labelledby`、由描述生成 `aria-describedby`、焦点锁定、滚动锁定、关闭后的焦点恢复、遮罩点击、Esc 关闭以及滑动手势。

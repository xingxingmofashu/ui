title: "Radio Group"

---

`RadioGroup` 渲染一组带标签的圆形玻璃单选控件。每个选项都可以包含标签与说明文字，整行都可以点击。

选项通过 `items` 数组传入，每个条目的 `value` 对应 group 的选中值。方向键会在选项之间移动选择，选中的值通过隐藏的原生单选输入框随表单提交。

## 基础示例

`label` 与 `description` 用于命名分组并说明用途。设置 `defaultValue` 可以指定初始选中项；也可以用 `value` 与 `onValueChange` 完全控制选中值。

<Example name="radio-group/basic" />

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。控件、指示器、标签、描述与间距会一起缩放。

<Example name="radio-group/sizes" />

## 受控用法

`value` 与 `onValueChange` 让选中值完全由外部状态控制。`onValueChange` 也会收到事件详情。

<Example name="radio-group/controlled" />

## 禁用与只读

在 group 上设置 `disabled` 会禁用所有选项；在单个 item 上设置 `disabled` 只会禁用该选项。`readOnly` 保留焦点，但不允许修改选中值。

<Example name="radio-group/disabled" />

## 无障碍

`RadioGroup` 暴露 `radiogroup`，由 `label` 或 `aria-label` / `aria-labelledby` 命名。每个选项都是 radio，可见的 `label` 与 `description` 会自动关联。

方向键在选项之间移动并更新选择，`Space` 选中当前选项。选中值通过隐藏的原生 radio 提交；必须选择时请设置 `required`。表单模式见[可访问性指南](/docs/zh/guides/accessibility)。

## 主题

组件使用共享玻璃材质。可以在父级调整 `--ui-glass-*` token，用 `className` 控制布局，并通过 `ui` 按 `data-slot` 调整内部槽位。组件级数值位于 `src/theme/radio-group.ts`。Token 分层与预设见[主题指南](/docs/zh/guides/theming)。

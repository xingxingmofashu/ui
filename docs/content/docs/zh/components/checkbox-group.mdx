title: "Checkbox Group"
description: "一个 React 复选框组，采用 Liquid Glass 控件，支持标签与描述。"
---

`CheckboxGroup` 渲染一组带标签、共享状态的独立复选框。每个选项都是真实的复选框，拥有自己的标签与说明，组值是所有选中项的 `value` 数组。

选项通过 `items` 数组传入。组件负责维护选中值，支持受控与非受控用法，并为整组提供统一的标签与说明。

## 基础示例

`label` 与 `description` 为分组命名并说明用途。通过 `defaultValue` 设置初始选中项，或使用 `value` 搭配 `onValueChange` 接管选中状态。

<Example name="checkbox-group/basic" />

## 父复选框

父复选框由 `Checkbox` 与 `CheckboxGroup` 组合实现，而不是分组的内置功能。在状态中保存选中值，根据状态推导父复选框的 `checked` 与 `indeterminate`，并在 `onCheckedChange` 中全选或清空所有选项。父复选框位于缩进的分组上方。为两个控件设置相同的 `size`，让两行保持对齐。

<Example name="checkbox-group/parent" />

## 嵌套父复选框

将第二个 `Checkbox` 与 `CheckboxGroup` 再缩进一级。每个父复选框由自己的数组推导，外层父复选框由两个数组共同推导。点击外层父复选框会同时更新两个数组，因此反复点击始终在全部选项与全不选之间切换。

## 受控用法

`value` 与 `onValueChange` 让选中状态完全由外部控制。回调会收到下一次的选中值数组与 Base UI 事件详情。

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。控件、标签、说明与间距会一起缩放。

<Example name="checkbox-group/sizes" />

## 禁用与只读

在分组上设置 `disabled` 会禁用全部选项；在单个 item 上设置只会禁用该选项。`readOnly` 保留每个复选框的焦点，但禁止修改选中状态。

<Example name="checkbox-group/disabled" />

## 表单用法

设置 `name` 后，每个选中项都会通过同名隐藏原生复选框提交。使用 `FormData.getAll(name)` 读取全部值。`form` 可将这些输入关联到文档其他位置的表单。

## 无障碍

`CheckboxGroup` 暴露 `group`，由 `label` 或 `aria-label` / `aria-labelledby` 命名。每个选项都是复选框，可见的 `label` 与 `description` 会自动关联。`Space` 切换当前复选框，`Tab` 在选项之间移动，因为复选框组不是复合控件。

父复选框是独立的 `Checkbox`：为分组提供自己的可访问名称，根据共享数组推导父复选框的 `checked` 与 `indeterminate`，并保持两层状态同步。父复选框只作为控件使用；除非为它设置 `name` 与 `value`，否则不会提交值。

禁用的选项仍会被播报，但无法修改。每个选中的选项都会提交自己的隐藏原生复选框；复选框组没有原生 `required`，请在表单提交处理函数中校验至少选中一个值。表单模式见[可访问性指南](/docs/zh/guides/accessibility)。

父复选框不属于组件 API。请使用 `Checkbox` 组合实现，并如上文所示同步数组状态。

`ui` 的键对应下方列出的 `data-slot` 值。其余 Base UI `CheckboxGroup` 属性都会透传；每个条目还会透传其余 Base UI `Checkbox` 属性。

| 属性 | 说明 |
| --- | --- |
| `data-disabled` | 分组或选项禁用时存在。 |
| `data-readonly` | 选项只读时存在。 |
| `data-required` | 选项必填时存在。 |
| `data-checked` | 选项选中时存在。 |
| `data-unchecked` | 选项未选中时存在。 |
| `data-indeterminate` | 选项处于混合状态时存在。 |
| `data-slot` | 标记分组内部结构（`root`、`header`、`label`、`description`、`items`）与每个控件（`item`、`box`、`fill`、`glass`、`overlay`、`indicator`、`indicator-icon`、`wrapper`、`item-label`、`item-description`）。 |

## 主题

组件复用共享玻璃材质与 `Checkbox` 的选项样式。可以在祖先元素上调整 `--ui-glass-*` token，通过 `--ui-checkbox-group-gap` 与 `--ui-checkbox-group-item-gap` 调整分组间距，并使用 `ui` 按 `data-slot` 调整内部槽位。`ui.item` 作用于每个选项根元素；单个条目的 `ui` 则指向同一组控件槽位。组件级数值位于 `src/theme/checkbox-group.ts`。Token 分层与预设见[主题指南](/docs/zh/guides/theming)。

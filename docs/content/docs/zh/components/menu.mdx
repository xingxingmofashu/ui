---
title: "Menu"
description: "支持分组、分隔线、图标、快捷键与受控状态的液态玻璃操作菜单。"
---

`Menu` 内部负责触发器、Portal、定位器、玻璃浮层、列表、操作项、分组与分隔线。默认情况下，选中操作项后会关闭菜单并调用对应的 `onSelect`。

操作项通过 `items` 数组传入。使用 `type: "group"` 创建带标题的分组，使用 `type: "separator"` 创建分隔线。每个操作项都需要唯一的 `value` 作为 React key；当可见标签不是纯文本时，请通过 `textValue` 提供键盘导航文本。

## 方位

`side`、`align`、`sideOffset` 与 `alignOffset` 控制浮层位置。空间不足时，菜单会自动翻转或偏移。

<Example name="menu/placement" />

## 受控状态

传入 `open` 与 `onOpenChange` 接管显示状态。除非同时从外部控制，触发器仍会切换菜单。

## API 参考

**Menu**

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `trigger` | `ReactElement` | — | 打开菜单的触发器。必填，必须转发 props 与 ref。 |
| `items` | `readonly MenuEntry[]` | — | 菜单中的操作项、分组与分隔线。 |
| `side` | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` | 首选方位。 |
| `align` | `"start" \| "center" \| "end"` | `"start"` | 相对触发器的对齐方式。 |
| `sideOffset` | `number \| OffsetFunction` | `8` | 触发器与菜单的像素距离。 |
| `alignOffset` | `number \| OffsetFunction` | `0` | 沿对齐轴的像素偏移。 |
| `collisionPadding` | `Padding` | `每边 5px` | 浮层与碰撞边界之间的留白。 |
| `open` | `boolean` | — | 受控显示状态。 |
| `defaultOpen` | `boolean` | `false` | 非受控时的初始显示状态。 |
| `onOpenChange` | `(open: boolean, details) => void` | — | 打开或关闭时调用。 |
| `onOpenChangeComplete` | `(open: boolean) => void` | — | 打开或关闭动画结束后调用。 |
| `modal` | `boolean` | `true` | 打开时锁定外部交互。 |
| `loopFocus` | `boolean` | `true` | 键盘焦点在菜单项之间循环。 |
| `disabled` | `boolean` | `false` | 禁止打开菜单。 |
| `className` | `string` | — | 合并到浮层的 Tailwind 类名。 |
| `ui` | `{ positioner?: ClassValue; popup?: ClassValue; glass?: ClassValue; overlay?: ClassValue; list?: ClassValue; item?: ClassValue; itemIcon?: ClassValue; itemLabel?: ClassValue; shortcut?: ClassValue; group?: ClassValue; groupLabel?: ClassValue; separator?: ClassValue }` | — | 按 `data-slot` 组织的内部槽位类名。 |

**MenuItemProps**

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | — | 唯一值，用于 React key 与导航。必填。 |
| `label` | `ReactNode` | — | 操作项中的可见内容。必填。 |
| `textValue` | `string` | — | 键盘导航使用的纯文本标签；字符串标签会自动使用。 |
| `icon` | `ReactNode` | — | 标签前的装饰性图标。 |
| `shortcut` | `ReactNode` | — | 标签后的快捷键提示。 |
| `onSelect` | `(event) => void` | — | 选中操作项时调用。 |
| `disabled` | `boolean` | `false` | 禁用该操作项。 |
| `closeOnClick` | `boolean` | `true` | 选中后是否关闭菜单。 |
| `className` | `string` | — | 合并到操作项的 Tailwind 类名。 |
| `ui` | `{ item?: ClassValue; itemIcon?: ClassValue; itemLabel?: ClassValue; shortcut?: ClassValue }` | — | 该操作项内部槽位的类名。 |

**MenuGroupProps**

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `type` | `"group"` | — | 标记为分组。必填。 |
| `label` | `ReactNode` | — | 分组标题。必填。 |
| `items` | `readonly MenuItemProps[]` | — | 分组内的操作项。必填。 |
| `className` | `string` | — | 合并到分组的 Tailwind 类名。 |
| `ui` | `{ group?: ClassValue; groupLabel?: ClassValue; item?: ClassValue; itemIcon?: ClassValue; itemLabel?: ClassValue; shortcut?: ClassValue }` | — | 分组及其操作项内部槽位的类名。 |

**MenuSeparatorProps**

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `type` | `"separator"` | — | 标记为分隔线。必填。 |
| `className` | `string` | — | 合并到分隔线的 Tailwind 类名。 |
| `ui` | `{ separator?: ClassValue }` | — | 分隔线槽位的类名。 |

| 属性 | 说明 |
| --- | --- |
| `data-highlighted` | 键盘或指针高亮该操作项时存在。 |
| `data-disabled` | 菜单或操作项禁用时存在。 |
| `data-popup-open` | 菜单打开时存在于触发器上。 |
| `data-side` | 浮层的实际方位。 |
| `data-starting-style` | 浮层开始进入动画时存在。 |
| `data-ending-style` | 浮层正在退出动画时存在。 |
| `data-slot` | 标记内部结构（`positioner`、`popup`、`glass`、`overlay`、`list`、`item`、`item-icon`、`item-label`、`shortcut`、`group`、`group-label`、`separator`）。 |

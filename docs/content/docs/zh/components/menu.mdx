`Menu` 内部负责触发器、Portal、定位器、玻璃浮层、列表、操作项、分组与分隔线。默认情况下，选中操作项后会关闭菜单并调用对应的 `onSelect`。

操作项通过 `items` 数组传入。使用 `type: "group"` 创建带标题的分组，使用 `type: "separator"` 创建分隔线。每个操作项都需要唯一的 `value` 作为 React key；当可见标签不是纯文本时，请通过 `textValue` 提供键盘导航文本。

## 定位

`side`、`align`、`sideOffset` 与 `alignOffset` 控制浮层位置。空间不足时，菜单会自动翻转或偏移。

## 受控用法

传入 `open` 与 `onOpenChange` 接管显示状态。除非同时从外部控制，触发器仍会切换菜单。

## 无障碍

`Menu` 遵循菜单按钮模式：触发器暴露 `aria-haspopup="menu"`、`aria-expanded` 与 `aria-controls`；内部列表带有 `role="menu"`，每个操作项都是 `menuitem`。`ArrowDown` 与 `ArrowUp` 在启用的操作项之间移动，typeahead 会匹配操作项标签。`Enter` 或 `Space` 激活高亮项，`Escape` 关闭菜单并把焦点返回触发器。

禁用的操作项仍会被播报，但无法激活。`value` 只作为 React key。当 `label` 不是纯文本时，请传入 `textValue` 供 typeahead 使用，并在操作项需要可访问名称时传入 `aria-label` 或 `aria-labelledby`。共享交互模式见[可访问性指南](/docs/zh/guides/accessibility)。

| `sideOffset` | `number \| OffsetFunction` | `8` | 触发器与菜单的像素距离。 |
| `alignOffset` | `number \| OffsetFunction` | `0` | 沿对齐轴的像素偏移。 |
| `collisionPadding` | `Padding` | `每边 5px` | 浮层与碰撞边界之间的留白。 |

| `style` | `CSSProperties` | — | 内联样式，合并到与 `className` 相同的元素。 |

**MenuSeparatorProps**

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |

| `data-closed` | 浮层关闭或正在关闭时存在。 |
| `data-highlighted` | 键盘或指针高亮该操作项时存在。 |
| `data-disabled` | 菜单或操作项禁用时存在。 |
| `data-popup-open` | 菜单打开时存在于触发器上。 |

| `data-align` | 实际对齐方式（`start`、`center` 或 `end`）。 |

| `data-ending-style` | 浮层正在退出动画时存在。 |
| `data-slot` | 标记内部结构（`positioner`、`popup`、`glass`、`overlay`、`list`、`item`、`item-icon`、`item-label`、`shortcut`、`group`、`group-label`、`separator`）。 |

## 主题

组件使用共享玻璃材质。可以在父级调整 `--ui-glass-*` token，用 `className` 控制布局，并通过 `ui` 按 `data-slot` 调整内部槽位。组件级数值位于 `src/theme/menu.ts`。Token 分层与预设见[主题指南](/docs/zh/guides/theming)。

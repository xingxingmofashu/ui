---
title: "Button"
description: "带液态玻璃表面的按钮，支持图标、尺寸与无障碍名称约束。"
---

`className` 作用于外层点击区域，可见的玻璃表面由内部 `glass` 槽位绘制。图标按钮必须提供 `aria-label` 或 `aria-labelledby`，否则类型检查会报错。

## 基础示例

下面的计数器直接渲染真实 `Button`。点击按钮会更新 React 状态，重置按钮在计数为零时自动禁用。

<ButtonBasic />

```tsx
"use client";

import { Button } from "@xingxingmofashu.me/ui";
import { Plus, RotateCcw } from "lucide-react";
import * as React from "react";

export function ButtonExample() {
  const [count, setCount] = React.useState(0);

  return (
    <div className="flex flex-wrap items-center gap-3">
      <Button
        label="增加计数"
        leadingIcon={<Plus />}
        onClick={() => setCount((value) => value + 1)}
      />
      <Button
        size="sm"
        label="重置"
        leadingIcon={<RotateCcw />}
        onClick={() => setCount(0)}
        disabled={count === 0}
      />
      <span aria-live="polite" className="text-sm text-ink/70">
        已点击 {count} 次
      </span>
    </div>
  );
}
```

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。文字和图标会随尺寸缩放，不需要给图标单独传 `size`。

<ButtonSizes />

| 尺寸 | 高度 | 图标 |
| --- | --- | --- |
| `xs` | 24px | 16px |
| `sm` | 28px | 16px |
| `md` | 32px | 20px |
| `lg` | 36px | 20px |
| `xl` | 40px | 24px |

```tsx
<Button size="xs" label="XS" trailingIcon={<ArrowRight />} />
<Button size="sm" label="SM" trailingIcon={<ArrowRight />} />
<Button size="md" label="MD" trailingIcon={<ArrowRight />} />
<Button size="lg" label="LG" trailingIcon={<ArrowRight />} />
<Button size="xl" label="XL" trailingIcon={<ArrowRight />} />
```

## 图标

前置图标位于文字左侧，后置图标位于文字右侧。两个图标使用相同的普通容器；有可见文字时，图标会自动标记为装饰性。

<ButtonIcons />

```tsx
import { Button } from "@xingxingmofashu.me/ui";
import { ArrowRight, Plus, Search } from "lucide-react";

<Button label="新建" leadingIcon={<Plus />} />
<Button label="搜索" leadingIcon={<Search />} />
<Button label="继续" trailingIcon={<ArrowRight />} />
<Button aria-label="下一步" leadingIcon={<ArrowRight />} />;
```

<Callout title="仅图标按钮">
  仅图标按钮没有可见文字，必须通过 `aria-label` 或 `aria-labelledby` 提供无障碍名称。
  遗漏时会在 TypeScript 层被拒绝。
</Callout>

## 状态

禁用状态使用原生 `disabled`，键盘与指针交互都会停止。

<ButtonStates />

```tsx
<Button label="保存" trailingIcon={<ArrowRight />} />
<Button label="不可用" disabled />
```

## 全宽按钮

`className` 调整外层点击区域，内部的 `base` 布局会自动填满可用宽度：

<ButtonFullWidth />

```tsx
<Button label="全宽" className="w-full" />
```

## 渲染为链接

需要导航而不是触发操作时，可以告诉 Base UI 不要渲染原生 `<button>`：

<ButtonLink />

```tsx
<Button
  nativeButton={false}
  render={<a href="/zh/docs" />}
  label="阅读文档"
  trailingIcon={<ArrowRight />}
/>
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 按钮文字。与 `children` 同时提供时优先使用 `label`。 |
| `children` | `ReactNode` | — | `label` 未提供时使用的可见内容。 |
| `leadingIcon` | `ReactNode` | — | 标签前的图标。 |
| `trailingIcon` | `ReactNode` | — | 标签后的图标，使用与前置图标相同的容器。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制高度、内边距和图标尺寸。 |
| `className` | `string` | — | 合并到外层 `root`。 |
| `ui` | `Partial<Record<ButtonSlot, string>>` | — | 覆盖内部槽位样式。 |

`label`、`children`、`aria-label`、`aria-labelledby` 至少提供一个，否则类型检查会失败。其余属性会透传给 Base UI 的 `Button`，例如 `disabled`、`onClick`、`type`、`render`。

### ui 槽位

| 槽位 | 说明 |
| --- | --- |
| `root` | 外层点击区域。 |
| `base` | 布局、hover 位移与按压缩放。 |
| `glass` | 可见的玻璃胶囊，承载共享玻璃材质。 |
| `label` | 文字容器。 |
| `leadingIcon` | 前置图标容器。 |
| `trailingIcon` | 后置图标容器。 |
| `overlay` | 玻璃边缘高光层。 |

## 无障碍

- 可见文字通过 `label` 或 `children` 提供。
- 仅图标按钮必须提供 `aria-label` 或 `aria-labelledby`。
- 禁用状态使用原生 `disabled`，并同步到 Base UI 的交互状态。

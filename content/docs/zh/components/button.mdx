---
title: "Button"
description: "带液态玻璃表面的按钮，支持图标、尺寸与无障碍名称约束。"
---

`className` 作用于外层点击区域，可见的玻璃表面由内部 `base` 槽位绘制。图标按钮必须提供 `aria-label` 或 `aria-labelledby`，否则类型检查会报错。

## 尺寸

支持 `xs` / `sm` / `md` / `lg` / `xl`，默认 `md`。文字和图标会随尺寸档位缩放，不需要给图标单独传 `size`。

<ButtonSizes />

| 尺寸 | 高度 | 图标 |
| --- | --- | --- |
| `xs` | 24px | 16px |
| `sm` | 28px | 16px |
| `md` | 32px | 20px |
| `lg` | 36px | 20px |
| `xl` | 40px | 24px |

```tsx
<Button size="sm" label="Small" trailingIcon={<ArrowRight />} />
<Button size="md" label="Medium" trailingIcon={<ArrowRight />} />
<Button size="lg" label="Large" trailingIcon={<ArrowRight />} />
```

## 图标

前置图标位于文字左侧，后置图标位于文字右侧的圆形徽标内。有可见文字时，图标会自动标记为装饰性。

<ButtonIcons />

```tsx
import { Button } from "@xingxingmofashu.me/ui";
import { ArrowRight, Plus, Search } from "lucide-react";

<Button label="新建" leadingIcon={<Plus />} />
<Button label="搜索" leadingIcon={<Search />} />
<Button label="继续" trailingIcon={<ArrowRight />} />
<Button aria-label="下一步" leadingIcon={<ArrowRight />} />;
```

<Callout title="仅图标按钮">
  仅图标按钮没有可见文字，必须通过 `aria-label` 提供无障碍名称。遗漏时会在
  TypeScript 层被拒绝。
</Callout>

## 状态

禁用状态使用原生 `disabled`，键盘与指针交互都会停止。

<ButtonStates />

```tsx
<Button label="保存" trailingIcon={<ArrowRight />} />
<Button label="不可用" disabled />
```

## 全宽按钮

`className` 调整外层点击区域，`classNames.base` 调整可见玻璃表面：

```tsx
<Button
  label="全宽"
  className="w-full"
  classNames={{ base: "w-full" }}
/>
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 按钮文字，也可以使用 `children`。 |
| `children` | `ReactNode` | — | 与 `label` 等价的可见内容。 |
| `leadingIcon` | `ReactNode` | — | 标签前的图标。 |
| `trailingIcon` | `ReactNode` | — | 标签后的图标，位于圆形徽标内。 |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | 控制高度、内边距和图标尺寸。 |
| `className` | `string` | — | 合并到外层 `root`。 |
| `classNames` | `Partial<Record<ButtonSlot, string>>` | — | 覆盖内部槽位样式。 |

其余属性会透传给 Base UI 的 `Button`，例如 `disabled`、`onClick`、`type`、`render`。

### classNames 槽位

| 槽位 | 说明 |
| --- | --- |
| `root` | 外层点击区域。 |
| `base` | 可见的玻璃胶囊。 |
| `label` | 文字容器。 |
| `leadingIcon` | 前置图标容器。 |
| `trailingIcon` | 后置图标容器。 |
| `overlay` | 玻璃边缘高光层。 |

## 无障碍

- 可见文字通过 `label` 或 `children` 提供。
- 仅图标按钮必须提供 `aria-label` 或 `aria-labelledby`。
- 禁用状态使用原生 `disabled`，并同步到 Base UI 的交互状态。

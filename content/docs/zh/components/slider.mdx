---
title: "Slider"
description: "带液态玻璃滑块、标签和数值显示的滑块，支持单值、区间与纵向布局。"
---

Slider 基于 Base UI 的 `Slider.Root`，支持受控与非受控用法。每个滑块都必须有完整的可访问名称：使用可见 `label`，或为外部标签提供 `aria-label` / `aria-labelledby`，否则类型检查会报错。

## 基础示例

下面的音量滑块直接渲染真实组件。拖动玻璃滑块、点击轨道或使用方向键都会更新数值，右侧的数值显示会自动跟随。

<SliderBasic />

```tsx
"use client";

import { Slider } from "@xingxingmofashu.me/ui";
import * as React from "react";

export function VolumeSlider() {
  const [volume, setVolume] = React.useState(40);

  return (
    <Slider
      label="音量"
      description="拖动玻璃滑块，或使用方向键调整。"
      showValue
      value={volume}
      onValueChange={setVolume}
    />
  );
}
```

## 区间值

传入数组会为每个值渲染一个滑块。`format` 使用 `Intl.NumberFormatOptions` 格式化 `Slider.Value` 的显示内容：

<SliderRange />

```tsx
<Slider
  label="价格区间"
  description="每个值对应一个滑块，数值通过 Intl.NumberFormat 格式化。"
  defaultValue={[25, 75]}
  showValue
  format={{ style: "currency", currency: "USD" }}
/>
```

## 纵向

`orientation="vertical"` 会把轨道、指示条和滑块切换为纵向布局：

<SliderVertical />

```tsx
<Slider
  aria-label="等级"
  orientation="vertical"
  defaultValue={60}
  ui={{ control: "h-48" }}
/>
```

## 禁用

禁用状态使用原生 `disabled`，拖动和键盘交互都会停止：

<SliderDisabled />

```tsx
<Slider aria-label="禁用滑块" defaultValue={35} disabled />
```

## 表单用法

Slider 会把 `name` 透传给 Base UI，并通过隐藏的 `input[type="range"]` 提交当前值：

<SliderForm />

```tsx
"use client";

import { Button, Slider } from "@xingxingmofashu.me/ui";
import { ArrowRight } from "lucide-react";
import * as React from "react";

export function VolumeForm() {
  const [submitted, setSubmitted] = React.useState<string | null>(null);

  function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const data = new FormData(event.currentTarget);
    setSubmitted(String(data.get("volume") ?? ""));
  }

  return (
    <form onSubmit={handleSubmit} className="flex flex-col gap-4">
      <Slider
        name="volume"
        label="音量"
        description="提交表单时会通过隐藏的 range input 发送当前值。"
        defaultValue={40}
        showValue
      />
      <div className="flex flex-wrap items-center justify-between gap-4">
        <Button
          type="submit"
          size="sm"
          label="提交"
          trailingIcon={<ArrowRight />}
        />
        <p aria-live="polite" className="text-sm text-ink/70">
          {submitted === null ? "尚未提交" : `提交值：${submitted}`}
        </p>
      </div>
    </form>
  );
}
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 可见标签，会与每个滑块建立 `aria-labelledby` 关联。 |
| `description` | `ReactNode` | — | 辅助说明，会与每个滑块建立 `aria-describedby` 关联。 |
| `showValue` | `boolean` | `false` | 在 header 中渲染当前值或区间。 |
| `value` | `number \| readonly number[]` | — | 受控值；数组会渲染多个滑块。 |
| `defaultValue` | `number \| readonly number[]` | — | 非受控初始值。 |
| `onValueChange` | `(value, details) => void` | — | 值变化时触发。 |
| `min` | `number` | `0` | 最小值。 |
| `max` | `number` | `100` | 最大值。 |
| `step` | `number` | `1` | 方向键和拖动的步进。 |
| `largeStep` | `number` | `10` | Page Up / Page Down 与 Shift + 方向键的步进。 |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | 布局与键盘方向。 |
| `format` | `Intl.NumberFormatOptions` | — | 数值显示格式。 |
| `locale` | `Intl.LocalesArgument` | — | 数值格式化使用的 locale。 |
| `disabled` | `boolean` | `false` | 禁用滑块。 |
| `name` | `string` | — | 表单提交时使用的字段名。 |
| `className` | `string` | — | 合并到最外层 `root`。 |
| `style` | `CSSProperties` | — | 合并到 `root` 的内联样式。 |
| `ui` | `Partial<Record<SliderSlot, string>>` | — | 覆盖内部槽位样式。 |

其余属性会透传给 Base UI 的 `Slider.Root`。

### ui 槽位

| 槽位 | 说明 |
| --- | --- |
| `root` | 最外层容器，包含标签、轨道和说明。 |
| `header` | 标签与数值显示区域。 |
| `label` | 可见标签。 |
| `value` | 当前值或区间。 |
| `description` | 辅助说明。 |
| `control` | 轨道与滑块的交互容器。 |
| `track` | 滑块轨道。 |
| `indicator` | 已选区间填充条。 |
| `thumb` | 液态玻璃滑块。 |

## 结构与尺寸

- Slider 没有 `size` 属性，固定使用 6px 轨道和 40 × 24px 滑块；纵向布局会交换宽高。
- 纵向布局的最小高度由 `control` 的 `min-h-40` 提供，需要更高时通过 `ui.control` 覆盖。
- 轨道与滑块的颜色、模糊和边缘高光来自 `--ui-glass-*` 与 Slider 内部变量，可在 `packages/ui/src/theme/slider.ts` 中调整。

## 无障碍

- 必须提供 `label`、`aria-label` 或 `aria-labelledby` 之一。
- `description` 会自动关联为 `aria-describedby`。
- 方向键调整步进，Page Up / Page Down 与 Shift + 方向键使用 `largeStep`。
- 每个滑块的当前值通过 `aria-valuenow`、`aria-valuemin` 和 `aria-valuemax` 暴露给辅助技术。

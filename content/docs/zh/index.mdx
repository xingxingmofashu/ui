这里是 Liquid Glass UI（`@xingxingmofashu.me/ui`）的文档站。组件基于 React 19 与 Tailwind CSS 4；Button 与 Switch 使用 Base UI，Card 使用原生结构。表面、边框高光与内阴影全部由 CSS 绘制，没有贴图，也没有额外的运行时。

整个文档站使用黑白主题：导航、代码高亮、提示框与组件预览都保持中性色。下面的卡片、按钮与开关直接来自 UI 包本身。

## 设计原则

- **真实组件**：文档通过 MDX 直接渲染 `@xingxingmofashu.me/ui`，预览与组件源码完全一致。
- **黑白优先**：文档使用 Fumadocs 的黑色主题，并覆盖提示框与代码高亮为中性色。
- **可访问**：按钮与开关在缺少无障碍名称时会在 TypeScript 层被拒绝。
- **可覆盖**：`className` 控制根元素，`classNames` 控制内部槽位，token 控制主题。

<Callout title="关于预览">
  预览中的 Switch 仍然使用真实组件，只通过内联变量把绿色轨道替换成黑白色。组件行为、焦点管理与动画都没有改变。
</Callout>

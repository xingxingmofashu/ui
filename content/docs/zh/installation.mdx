description: "在当前 monorepo workspace 中引入 UI 包、样式与 Tailwind 源文件。"
---

`@xingxingmofashu.me/ui` 是当前 workspace 的私有包，不会发布到 npm。它直接导出 TypeScript 源码，因此需要让应用编译包源码，并让 Tailwind 扫描组件文件。下面的步骤适用于本仓库内的 Next.js 应用。

## 前置条件

- pnpm workspace；根目录的 `pnpm-workspace.yaml` 已包含 `packages/*`。
- React 19。
- Tailwind CSS 4。

## 添加依赖

在应用的 `package.json` 中通过 `workspace:*` 引用 UI 包：

```json title="package.json"
{
  "dependencies": {
    "@xingxingmofashu.me/ui": "workspace:*"
  }
}
```

然后安装依赖：

```bash
pnpm install
```

## 配置 Next.js

把 UI 包加入 `transpilePackages`，让 Next.js 编译包内的 TypeScript 与 JSX：

```ts title="next.config.ts"
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  transpilePackages: ["@xingxingmofashu.me/ui"],
};

export default nextConfig;
```

<Callout title="为什么需要这一步">
  UI 包导出的是源码，而不是预编译产物。跳过这一步通常会在构建时看到 JSX 或
  TypeScript 解析错误。
</Callout>

## 导入样式

在应用的全局 CSS 中导入 Tailwind 与 UI 包 token，并让 Tailwind 扫描组件源码：

```css title="app/globals.css"
@import "tailwindcss";
@import "@xingxingmofashu.me/ui/index.css";

@source "../../ui/src";
```

`@source` 的路径相对于当前 CSS 文件。请根据实际目录调整；本仓库的文档站与示例站点都位于 `packages` 下，因此使用 `../../ui/src`。

## 使用组件

```tsx
import { Button, Card, Switch } from "@xingxingmofashu.me/ui";
import { ArrowRight } from "lucide-react";

export function Example() {
  return (
    <Card
      title="液态玻璃"
      description="纯 CSS 磨砂玻璃面板。"
      footer={
        <Button
          size="sm"
          label="继续"
          trailingIcon={<ArrowRight />}
        />
      }
    >
      <Switch label="启用通知" description="新消息会推送到你的邮箱。" />
    </Card>
  );
}
```

## 明暗模式

组件通过 `.light` / `.dark` 类名读取 token。使用 `next-themes` 在根元素切换 `class` 即可：

```tsx title="app/layout.tsx"
import { ThemeProvider } from "next-themes";

<html lang="zh-CN" suppressHydrationWarning>
  <body>
    <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
      {children}
    </ThemeProvider>
  </body>
</html>;
```

如果项目使用 Fumadocs，`RootProvider` 已经内置 `next-themes`，不需要重复添加。

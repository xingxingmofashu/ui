Liquid Glass UI is the documentation site for `@xingxingmofashu.me/ui`. The components are built with React 19, Tailwind CSS 4, and Base UI. Surfaces, rim highlights, and inner shadows are all drawn with CSS — no textures and no extra runtime.

The documentation uses a black-and-white theme: navigation, syntax highlighting, callouts, and component previews all stay neutral. The card, buttons, and switches below render directly from the UI package.

## Design principles

- **Real components**: docs render `@xingxingmofashu.me/ui` directly through MDX, so previews match the published code.
- **Monochrome first**: the docs use Fumadocs' black theme and override callouts and syntax highlighting to neutral colors.
- **Accessible**: buttons and switches without an accessible name are rejected at the TypeScript level.
- **Overridable**: `className` targets the root, `classNames` targets internal slots, and tokens control the theme.

<Callout title="About previews">
  The switches in previews are still the real component. Only the green track is replaced with black and white through inline variables. Behavior, focus management, and animation are unchanged.

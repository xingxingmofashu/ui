Card uses two layers: one draws the glass surface and highlights, the other lays out content. `className` targets `root`, while `ui` overrides each internal slot.

<CardPreview />

## Basic usage

```tsx
import { Button, Card } from "@xingxingmofashu.me/ui";
import { ArrowRight } from "lucide-react";

<Card
  className="max-w-md"
  title="Liquid glass"
  description="A CSS-only frosted glass panel."
  footer={<Button size="sm" label="View" trailingIcon={<ArrowRight />} />}
>
  <div className="text-sm text-ink/70">
    Place the card over a detailed background to see the glass effect.
  </div>
</Card>;
```

## Content only

When `title`, `description`, or `footer` are omitted, the corresponding region is not rendered:

```tsx
<Card className="max-w-sm">
  <div className="text-sm text-ink/70">A card with only a body.</div>
</Card>
```

## Custom slots

`ui` overrides internal structure such as header, body, and title, while `className` always targets the root:

```tsx
<Card
  className="max-w-md"
  ui={{
    header: "border-b border-glass-border",
    body: "bg-glass-surface/50",
    title: "tracking-tight",
  }}
  title="Custom styles"
  description="Adjust internal structure with ui."
>
  <div className="text-sm text-ink/70">The default slot goes here.</div>
</Card>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | Card heading. |
| `description` | `ReactNode` | — | Supporting text below the heading. |
| `footer` | `ReactNode` | — | Footer action area. |
| `children` | `ReactNode` | — | Card body content. |
| `className` | `string` | — | Merged into `root`. |
| `ui` | `Partial<Record<CardSlot, string>>` | — | Overrides internal slot styles. |

All other props are forwarded to the root `div`, such as `id`, `role`, and `onClick`.

### ui slots

| Slot | Description |
| --- | --- |
| `root` | Outermost container. |
| `header` | Title and description region. |
| `title` | Heading element. |
| `description` | Description element. |
| `body` | Main content region. |
| `footer` | Footer region. |

## Structure notes

- Card has no `size` prop. The header and footer use `p-4 sm:px-6`; the body uses `p-4 sm:p-6`.
- Empty strings, `false`, and empty arrays for `title`, `description`, `footer`, or `children` also skip rendering the corresponding region.
- The title uses `font-semibold`; the description uses `mt-1 text-sm`.
- The card itself is not a button. If the whole card should be clickable, add `role`, keyboard behavior, and focus styles at the call site.
- The glass effect needs background detail to show. It stays subtle on flat backgrounds.

---
title: "Slider"
description: "A slider with a liquid glass thumb, label, and value display, supporting single values, ranges, and vertical orientation."
---

Slider is built on Base UI's `Slider.Root` and supports controlled and uncontrolled usage. Every slider must have a complete accessible name: use a visible `label`, or provide `aria-label` / `aria-labelledby` for an external label, otherwise type checking fails.

## Basic example

The volume slider below renders the real component. Dragging the glass thumb, clicking the track, or using the arrow keys updates the value, and the value display follows automatically.

<SliderBasic />

```tsx
"use client";

import { Slider } from "@xingxingmofashu.me/ui";
import * as React from "react";

export function VolumeSlider() {
  const [volume, setVolume] = React.useState(40);

  return (
    <Slider
      label="Volume"
      description="Drag the glass thumb or use the arrow keys."
      showValue
      value={volume}
      onValueChange={setVolume}
    />
  );
}
```

## Range values

Passing an array renders one thumb per value. `format` uses `Intl.NumberFormatOptions` to format the value shown by `Slider.Value`:

<SliderRange />

```tsx
<Slider
  label="Price range"
  description="One thumb per value, formatted with Intl.NumberFormat."
  defaultValue={[25, 75]}
  showValue
  format={{ style: "currency", currency: "USD" }}
/>
```

## Vertical

`orientation="vertical"` switches the track, indicator, and thumb to a vertical layout:

<SliderVertical />

```tsx
<Slider
  aria-label="Level"
  orientation="vertical"
  defaultValue={60}
  ui={{ control: "h-48" }}
/>
```

## Disabled

The disabled state uses the native `disabled` attribute, stopping both dragging and keyboard interaction:

<SliderDisabled />

```tsx
<Slider aria-label="Disabled slider" defaultValue={35} disabled />
```

## Form usage

Slider forwards `name` to Base UI and submits the current value through a hidden `input[type="range"]`:

<SliderForm />

```tsx
"use client";

import { Button, Slider } from "@xingxingmofashu.me/ui";
import { ArrowRight } from "lucide-react";
import * as React from "react";

export function VolumeForm() {
  const [submitted, setSubmitted] = React.useState<string | null>(null);

  function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const data = new FormData(event.currentTarget);
    setSubmitted(String(data.get("volume") ?? ""));
  }

  return (
    <form onSubmit={handleSubmit} className="flex flex-col gap-4">
      <Slider
        name="volume"
        label="Volume"
        description="The current value is submitted through a hidden range input."
        defaultValue={40}
        showValue
      />
      <div className="flex flex-wrap items-center justify-between gap-4">
        <Button
          type="submit"
          size="sm"
          label="Submit"
          trailingIcon={<ArrowRight />}
        />
        <p aria-live="polite" className="text-sm text-ink/70">
          {submitted === null ? "Not submitted yet" : `Submitted: ${submitted}`}
        </p>
      </div>
    </form>
  );
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | Visible label, connected to every thumb through `aria-labelledby`. |
| `description` | `ReactNode` | — | Supporting text, connected to every thumb through `aria-describedby`. |
| `showValue` | `boolean` | `false` | Renders the current value or range in the header. |
| `value` | `number \| readonly number[]` | — | Controlled value; an array renders multiple thumbs. |
| `defaultValue` | `number \| readonly number[]` | — | Uncontrolled initial value. |
| `onValueChange` | `(value, details) => void` | — | Called when the value changes. |
| `min` | `number` | `0` | Minimum value. |
| `max` | `number` | `100` | Maximum value. |
| `step` | `number` | `1` | Step for arrow keys and dragging. |
| `largeStep` | `number` | `10` | Step for Page Up / Page Down and Shift + arrow keys. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout and keyboard orientation. |
| `format` | `Intl.NumberFormatOptions` | — | Value display format. |
| `locale` | `Intl.LocalesArgument` | — | Locale used for number formatting. |
| `disabled` | `boolean` | `false` | Disables the slider. |
| `name` | `string` | — | Field name used when submitting a form. |
| `className` | `string` | — | Merged into the outermost `root`. |
| `style` | `CSSProperties` | — | Inline styles merged into `root`. |
| `ui` | `Partial<Record<SliderSlot, string>>` | — | Overrides internal slot styles. |

All other props are forwarded to Base UI's `Slider.Root`.

### ui slots

| Slot | Description |
| --- | --- |
| `root` | Outermost container with the label, track, and description. |
| `header` | Label and value display region. |
| `label` | Visible label. |
| `value` | Current value or range. |
| `description` | Supporting text. |
| `control` | Interactive container for the track and thumb. |
| `track` | Slider track. |
| `indicator` | Filled portion of the track. |
| `thumb` | Liquid glass thumb. |

## Structure and sizing

- Slider has no `size` prop and always uses a 6px track and a 40 × 24px thumb; vertical orientation swaps the dimensions.
- The vertical control has a `min-h-40` minimum height; override `ui.control` when you need more room.
- Track and thumb colors, blur, and rim highlights come from `--ui-glass-*` and Slider-local variables in `packages/ui/src/theme/slider.ts`.

## Accessibility

- Provide one of `label`, `aria-label`, or `aria-labelledby`.
- `description` is connected as `aria-describedby`.
- Arrow keys move by `step`; Page Up / Page Down and Shift + arrow keys use `largeStep`.
- Each thumb exposes its current value through `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`.

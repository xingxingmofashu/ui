title: "Theming"
description: "Override design tokens, switch between light and dark, and use Tailwind aliases."
---

Global design tokens live in `@xingxingmofashu.me/ui/index.css`. Button and Card read their colors from tokens; Switch track colors use component-local `--ui-switch-on` / `--ui-switch-off` variables and must be overridden separately. Component styles live in tailwind-variants recipes under `packages/ui/src/theme/*.ts`.

## Tokens

| Token | Purpose |
| --- | --- |
| `--ui-ink` | Primary text and icon color. |
| `--ui-ink-active` | Primary color while pressed. |
| `--ui-glass-surface` | Base color of the glass surface. |
| `--ui-glass-border` | Outer glass border. |
| `--ui-glass-focus` | Keyboard focus outline. |
| `--ui-glass-inner-border` | Inner highlight border. |
| `--ui-glass-rim` | Rim around the glass edge. |
| `--ui-glass-highlight` | Diagonal highlight. |
| `--ui-glass-glare-stop` | Position of the highlight gradient. |
| `--ui-glass-icon` | Reserved token; not used by the current built-in components. |
| `--ui-glass-icon-foreground` | Reserved token; not used by the current built-in components. |
| `--ui-drop-shadow-label` | Text drop shadow for Card titles. |
| `--ui-drop-shadow-icon` | Reserved token; not used by the current built-in components. |
| `--ui-shadow-glass` | Composite glass shadow. |
| `--ui-shadow-glass-icon` | Reserved token; not used by the current built-in components. |

See `packages/ui/src/index.css` for the full values. Reserved tokens are still available for custom styles, but overriding them does not change the current Button, Card, or Switch appearance.

## Override tokens

Override the variables in the application's global styles. It is best to update both `.light` and `.dark` so custom values survive theme changes:

```css title="app/globals.css"
:root,
.light {
  --ui-ink: #1f2937;
  --ui-glass-surface: rgb(255 255 255 / 0.4);
  --ui-glass-border: rgb(15 23 42 / 0.12);
}

.dark {
  --ui-ink: #f8fafc;
  --ui-glass-surface: rgb(15 23 42 / 0.4);
  --ui-glass-border: rgb(248 250 252 / 0.16);
}
```

<Callout title="Start with black and white">
  For a simple recolor, override `--ui-ink`, `--ui-glass-surface`, and
  `--ui-glass-border` first. Those three usually produce a consistent result. The docs
  themselves only use neutral colors.
</Callout>

## Light and dark mode

Components read tokens from the `.light` / `.dark` class. Use `next-themes` or a similar solution to switch the class on the root element:

```tsx title="app/layout.tsx"
import { ThemeProvider } from "next-themes";

<html lang="en" suppressHydrationWarning>
  <body>
    <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
      {children}
    </ThemeProvider>
  </body>
</html>;
```

## Tailwind aliases

`index.css` exposes ready-to-use utilities through `@theme inline`:

| Alias | Token |
| --- | --- |
| `text-ink` / `bg-ink` | `--ui-ink` |
| `text-ink-active` / `bg-ink-active` | `--ui-ink-active` |
| `bg-glass-surface` | `--ui-glass-surface` |
| `border-glass-border` | `--ui-glass-border` |
| `outline-glass-focus` | `--ui-glass-focus` |
| `border-glass-inner-border` | `--ui-glass-inner-border` |
| `border-glass-rim` | `--ui-glass-rim` |
| `bg-glass-highlight` | `--ui-glass-highlight` |
| `text-glass-icon` | `--ui-glass-icon` |
| `text-glass-icon-foreground` | `--ui-glass-icon-foreground` |
| `shadow-glass` | `--ui-shadow-glass` |
| `shadow-glass-icon` | `--ui-shadow-glass-icon` |

The icon-related aliases remain available, but the current built-in components do not use the corresponding tokens.

## Custom variants

The UI package registers two Tailwind custom variants, `ui-light` and `ui-dark`:

```tsx
<div className="bg-white ui-dark:bg-slate-900">...</div>
```

You can also use the application's own `dark` variant:

```css
@custom-variant dark (&:where(.dark, .dark *));
```

## Component-level overrides

Besides global tokens, each component supports:

- `className`: targets the component root.
- `classNames`: overrides internal slots, such as Button's `base`, Card's `body`, or Switch's `thumb`.

Component styles live in tailwind-variants recipes under `packages/ui/src/theme/*.ts`; `index.css` keeps global tokens, custom variants, and Tailwind aliases.

## Monochrome Switch track

The switch track colors are controlled by `--ui-switch-on` / `--ui-switch-off` inside the component. These variables are defined in `packages/ui/src/theme/switch.ts`, not in the global token file. The docs keep the real Switch and only override these variables inline:

```tsx
import type { CSSProperties } from "react";

<Switch
  label="Enable notifications"
  style={
    {
      "--ui-switch-on": "var(--docs-switch-on)",
      "--ui-switch-off": "var(--docs-switch-off)",
    } as CSSProperties
  }
/>
```

```css
:root {
  --docs-switch-on: #171717;
  --docs-switch-off: #cfcfcf;
}

.dark {
  --docs-switch-on: #fafafa;
  --docs-switch-off: #3f3f46;
}
```

## Fumadocs theme

The docs use Fumadocs' `black` theme with the Glass layout:

```css title="app/globals.css"
@import "tailwindcss";
@import "fumadocs-ui/css/generated/glass.css";
@import "fumadocs-ui/css/black.css";
@import "fumadocs-ui/css/preset.css";
@import "@xingxingmofashu.me/ui/index.css";

@source "../../ui/src";
```

Callout colors are also overridden, and syntax highlighting is grayscaled to keep the whole site monochrome.
